# B2 阶段定义

## 是什么

B2_IBM 是 IBM Framework 第二阶段——设计到交付。

## 输入

- milestones.md 中 `candidate_issues` 的 promoted candidate
- candidate 的 `acceptance_criteria`、`promotion_gate`、`decision_reason`

## 输出

- `docs/B2-docs/{epic}/{story}/raw-{key}/issues/I-{key}-A.md`（I-* issue）
- `docs/B2-docs/{epic}/{story}/raw-{key}/prd.md`
- `docs/B2-docs/{epic}/{story}/raw-{key}/verification/pre-tests.md`（全部 red-green-status = pending）
- `docs/B2-docs/{epic}/{story}/raw-{key}/verification/tasks.md`
- `docs/B2-docs/{epic}/{story}/raw-{key}/code-reviews/implementation-decision-note.md`
- `docs/milestones.md` 中 I-* committed_issues 条目（含真实路径）

## 完成标志

- I-* issue 的 phase_state = done_b2_ibm
- pre-tests.md 覆盖全部改动面，每条有真实 test_command
- tasks.md 任务分解完整
- Implementation Decision Note 5 字段完整
- milestones.md committed_issues 条目正确

## 完成后做什么

**调用 A2A PATCH state=input-required, reason=needs-review:b2**

Reviewer 按 `review-guidelines/b2-review.md` 审查设计产物。
pass → 进入 RED。fail → 补充/修复。
