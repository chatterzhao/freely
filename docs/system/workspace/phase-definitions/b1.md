# B1 阶段定义

## 是什么

B1_IBM 是 IBM Framework 第一阶段——问题到决策。

## 输入

- `docs/B1-docs/raw-{key}/issue.md`（wt-create 拉取的 raw issue）
- `docs/CONSTITUTION.md`、`docs/LAWS.md`、`docs/PROJECT_INTENT.md`
- 已有 `docs/milestones.md`、相关 epics

## 输出

- `docs/B1-docs/raw-{key}/brainstorms.md`（发散→收敛→决策）
- `docs/B1-docs/raw-{key}/candidates.md`（candidate 文档）
- `docs/milestones.md` 中的 `M-{key}-A` 条目（candidate 入队）

## 完成标志

- brainstorms.md 包含 Discovery/Problem/Brainstorm(至少 2 个 Option)/Decision/Candidate
- candidates.md 包含完整字段（status/milestone/decision/acceptance_criteria/promotion_gate）
- milestones.md candidate_issues 条目正确
- candidate status = promoted 或 absorbed

## 完成后做什么

**调用 A2A PATCH state=input-required, reason=needs-review:b1**

这将触发 Reviewer agent 按 `docs/system/workspace/review-guidelines/b1-review.md` 审查本阶段产出。

Reviewer pass → 进入 B2。
Reviewer fail → 根据 findings 补充或重做。
