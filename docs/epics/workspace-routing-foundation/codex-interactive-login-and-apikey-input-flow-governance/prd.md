# PRD: codex-interactive-login-and-apikey-input-flow-governance

## Objective

Define the smallest Codex-first interactive login contract that covers auth-mode selection, API-key input collection, and immediate live-bundle-plus-slot materialization.

## User-Facing Outcome

- Operators can run `freely ai login codex` and select `account` or `apikey` without guessing hidden mode rules.
- Operators can complete Codex API-key login through prompts or direct args and get a stable saved-slot result.

## Constraints

- No watchdog/bootstrap scope expansion.
- No generic multi-tool interactive login framework.
- No reopening of bundle/probe-routing governance beyond the already completed dependency owner.
