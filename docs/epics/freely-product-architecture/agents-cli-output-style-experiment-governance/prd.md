# PRD: agents-cli-output-style-experiment-governance

## Goal

Record the current AGENTS-only output-style experiment as a narrow product-architecture/developer-entrypoint rule, and clarify how Freely already generates and consumes project-level `AGENTS.md`.

## User/Operator Outcome

- Freely contributors get a stable default for human-readable CLI/chat replies while building Freely.
- The default stays concise and readable without switching to classical Chinese.
- The experiment remains visibly outside capability materialization scope.
- Freely self-hosting and user-project initialization both become easier to reason about because project-level `AGENTS.md` is stated as the first governance surface.

## Constraints

- No capability promotion.
- No runtime-facing output contract changes.
- No widening into token-efficiency benchmarking infrastructure.
