# Brainstorm: agents-cli-output-style-experiment-governance

## Focus

Freeze the smallest lawful owner for the current output-style experiment without promoting it into Freely capability truth.

## Narrowing Decisions

1. The artifact remains `AGENTS.md`, not `docs/system/**` or runtime-facing capability surfaces.
2. The default style is concise plain Chinese, not classical Chinese.
3. The rule applies only to developer-facing CLI/chat output while building Freely.
4. The owner exists to satisfy canonical governance writeback for a `develop` merge, not to widen the experiment into a reusable product feature.

## Excluded

1. No tokenizer benchmark suite.
2. No runtime output contract changes.
3. No new skill/agent/runtime capability materialization.
