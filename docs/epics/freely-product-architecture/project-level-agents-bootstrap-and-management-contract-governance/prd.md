# PRD: project-level-agents-bootstrap-and-management-contract-governance

## Goal

Make project-level `AGENTS.md` bootstrap, read-order, preservation, and self-hosting semantics explicit reusable Freely capability truth.

## User/Operator Outcome

- Managed projects get a predictable minimal `AGENTS.md` entrypoint when missing.
- Existing project-owned `AGENTS.md` is preserved rather than silently overwritten.
- Operators and self-hosting Freely can tell which rules belong in project entrypoint truth versus reusable workspace capability docs.

## Constraints

- Freeze current behavior first.
- No rich template manager in this slice.
- No silent runtime semantic drift beyond the documented preserve-existing contract.
