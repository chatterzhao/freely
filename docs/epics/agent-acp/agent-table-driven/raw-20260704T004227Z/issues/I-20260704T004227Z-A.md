# I-20260704T004227Z-A: 修复 ACP bridge 启动链路

- source_candidate: docs/pre-brainstorms/20260704T004227Z--agent-acp-table-driven/candidates.md#C-20260704T004227Z-A

## 问题

agent-table.toml 配置 `opencode-apikey-ds-flash-auto`，但实际推理使用 `claude-agent-acp` + `deepseek-v4-pro` 模型。

根因:
1. monitor-ai-acp.sh 的 `_bridge_ensure_running` 不传 `--acp-bin`（默认 claude-agent-acp），且 tool name 对比用全名 vs base名导致误杀 bridge
2. 父进程 Claude Code 的 `ANTHROPIC_*` 环境变量被 bridge 子进程继承
3. agent-id grep 子串匹配导致 develop 上解析出 worker_01

## 修复范围

| # | 文件 | 函数 | 改动 |
|---|------|------|------|
| 1a | monitor-ai-acp.sh | `_bridge_ensure_running` | tool name 对比改用 base_tool (`%%-*`) |
| 1b | monitor-ai-acp.sh | `_bridge_ensure_running` | 增加三层 ACP binary 解析 + `--acp-bin` 传递 |
| 1c | monitor-ai-acp.sh | `_bridge_ensure_running` | 写 `.bin` 文件 |
| 2a | freely | `_ensure_acp_bridge_running` | bridge 启动前 unset ANTHROPIC_*/CLAUDE_CODE_*/AI_AGENT |
| 2b | monitor-ai-acp.sh | `_bridge_ensure_running` | 同上 |
| 3 | freely | `load_config` + `_init_agent_table_slot_pin` | grep -F "$(pwd)=" 锚定行尾 |
| 4 | freely + monitor-ai-acp.sh | 多处 | 诊断日志 |
