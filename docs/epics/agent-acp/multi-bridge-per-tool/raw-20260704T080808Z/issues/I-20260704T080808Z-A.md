## 问题

## 修复范围

| # | 文件 | 改动 |
|---|------|------|
| 1 | `freely` | socket/pid 命名启用 `-{base_tool}` 后缀 |
| 2 | `freely` | daemon start 扫描 agent-table 唯一 base_tool → 逐启 bridge |
| 3 | `freely` | base_tool 不可解析 → 硬报错退出 |
| 4 | `freely` | daemon stop 清理所有 bridge |
| 5 | `agent_working.py` | `_resolve_bridge_socket` 启用 base_tool |
| 6 | `freely` | `_stop_acp_bridge` 参数化 (空=全停) |
