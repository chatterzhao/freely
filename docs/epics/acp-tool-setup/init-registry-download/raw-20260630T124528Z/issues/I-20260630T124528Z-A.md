# I-20260630T124528Z-A: freely init ACP 工具准备 + tool-registry 下载配置

- source_candidate: docs/pre-brainstorms/20260630T124528Z--acp-init-registry/candidates.md#C-20260630T124528Z-A
- verification_artifact_dir: docs/epics/acp-tool-setup/init-registry-download/code-reviews

## 实现

### 1. tool-registry.toml — 四个工具新增 install_method + download_url

每个 `[tool.acp]` 新增两个字段。download_url 为唯一合法下载源。

| 工具 | install_method | download_url |
|------|---------------|-------------|
| claude | `npm` | `npm:@anthropic-ai/claude-agent-acp` |
| codex | `github_release` | `https://github.com/zed-industries/codex-acp/releases/download/v{version}/codex-acp-{version}-{triplet}.tar.gz` |
| opencode | `npm` | `npm:@anthropic-ai/opencode` |
| cline | `npm` | `npm:cline` |

### 2. ensure-codex-acp → ensure-acp-binary 通用化

接受 `--tool <name>` 参数。从 tool-registry 读 `[<tool>].acp.download_url` + `install_method`，按方法执行下载。缓存路径 `~/.cache/freely/acp/<tool>/<version>/<triplet>/<binary>`。

### 3. cmd_init() 新增 ACP 工具准备步骤

循环 registry 每个 `[tool]` section → 搜系统 → 未找到则提示确认 → 按 download_url 下载 → 写入 config.toml (`FREELY_ACP_<TOOL>_BIN`)。

### 4. _ensure_acp_bridge_running 从 config.toml 读路径

优先读 `get_config "FREELY_ACP_${TOOL}_BIN"`，找到且可执行则直接用。找不到 fallback 到 PATH。

### 5. _acp_bridge_health_check Shell 注入修复

`sock.connect('$socket')` → `os.environ.get('FREELY_ACP_HEALTH_SOCKET')`
