# Epic Asset Directories

Use one directory per epic slug under this path.

Recommended layout:

- `docs/epics/<epic-slug>/EPIC.md`
- `docs/epics/<epic-slug>/stories/`
- `docs/epics/<epic-slug>/artifacts/`

Per-epic `progress.md` can be used as a summary, but must not replace `docs/continuity/PROGRESS.md` or `docs/progress/*` records.
