# Candidate: 彻底 A2A 重构

## Summary

将 Freely 的 agent 通信从自建 handoff 机制彻底重构为标准 A2A 协议。
集成官方 a2a-sdk==1.1.0，对齐 JiuwenSwarm 的 Gateway + Async AgentExecutor + Event-driven 模式，
新增双传输（Unix socket 本地 + TCP 远程）、Agent 发现、A2X-style 注册中心。

## Architecture Decisions

1. **官方 SDK**: 使用 `a2a.types` 标准类型（Task/Message/Artifact/AgentCard），
   `SQLiteTaskStore` 继承 `a2a.server.tasks.TaskStore`，
   `FreelyAgentExecutor` 继承 `a2a.server.agent_execution.AgentExecutor`

2. **AI 直出 A2A state**: 移除 exit_kind→state 翻译层，AI 的 prompt 直接要求输出
   `{"state":"completed","summary":"..."}` 格式

3. **AI reply = A2A Message**: AI 回复全文即 A2A Message (role/type/content)，
   通过 POST /tasks/{id}/messages 存储

4. **双传输**: A2A_LISTEN_MODE=unix|tcp|both，A2AClient 支持 unix:// 和 http://
   transport，Agent 发现通过扫描 /tmp/freely-a2a-*.sock

5. **A2X Registry**: a2a_registry.py 对齐 JiuwenSwarm 的 AgentRegistry 模式，
   支持 register/discover/heartbeat/deregister

6. **数据迁移**: 新增 delivery_status、worker_pid 列到 a2a_tasks，
   恢复 task_mode_gate 和 tool_failure_log 建表语句
