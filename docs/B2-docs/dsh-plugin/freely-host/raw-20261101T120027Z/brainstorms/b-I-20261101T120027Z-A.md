# b-I-E：DSH Freely-host 插件

## 问题

Freely 需要 DSH 的 Session/模型/工具，但 DSH 的 Router/Ticket 不能接管 loop。插件必须只做 harness，不造第二套调度。

## 方案

- 插件 bundle + profile patch 定义三角色 preset。
- `apply` 创建 manager session，注册 `freely_status` 工具；工具通过 `ctx.subprocess` 调 `bin/freely`。
- 工具白名单用 `agent.ctx.tools.restrict`；persona 用 `dsh-persona`。
- handoff 仍由 Freely DB/CLI 管，插件只 bridge。

## 边界

- 不加载 `dsh-superagent`；不接管 scan/gates。
- 真实 issue→PR 是 B2 E2E；P1 只到 session/tool bridge。
