# I-20261101T120027Z-A: @freely/dsh-freely Freely-host 插件

## Goal

做一个 DSH 插件：Freely 保留 loop，DSH 只提供 Session/Agent/模型/工具；P1 插件负责 Manager session、三角色 preset、工具白名单、subprocess bridge；handoff/A2A 不在本 P1。

## Scope（P1 打包）

- `packaging/dsh-freely` 包：`index.js` + `cordis.patch.yml` + `package.json`。
- 注入 `sessionController/workspaceRegistry/subprocess/tools`，创建 manager session。
- 三角色 preset（manager/worker/reviewer）+ 工具白名单 + persona。
- 工具 `freely_status` 通过 subprocess 调 `bin/freely`。
- 不加载 `dsh-superagent`；不做 DSH Router/Ticket。

## Non-goals

- 不做 Panel、DSH Source、多项目、headless/desktop。
- 不实现完整 A2A 协议；handoff/A2A 由上游 C-B 负责；issue→PR 由 successor raw `20261101T124657Z` 承接。
