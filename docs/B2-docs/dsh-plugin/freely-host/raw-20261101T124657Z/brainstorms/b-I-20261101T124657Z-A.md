# b-I-A：E2E driver

## 实现选择

- 用 DSH plugin `dsh-freely-e2e` 直接调 `sessionController`，worker/reviewer 用 e2e preset。
- Worker task：在 `config.repo` 写 `DONE.txt`，`git add/commit`；只 E2E preset 带 bash。
- Driver poll `resolveAgent(sid).agent.status` 到 idle；超时 fail。
- Reviewer task：读 `git show --stat`，输出 `VERDICT: pass|fail`。
- Driver 跑 `pretests-gate`，结果写 `result.json`。
- 不经过 ACP；不加载 dsh-superagent。
