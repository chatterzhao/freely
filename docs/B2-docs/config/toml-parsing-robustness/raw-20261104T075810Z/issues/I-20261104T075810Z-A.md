## 实现

- 新增 `contracts/config/schema.yaml`：覆盖 `.freely/config.toml` 全部 **58 个 flat key**（57 顶层 + `[skip_ibm_gate].allowed_paths`），每键声明 `type` / `default` / `scope` / `required` / `consumers`；`allowed_paths` 强制 `list[str]`。采用 YAML 1.2 的 JSON 兼容子集，`json.loads` 与 `yaml.safe_load` 双可读，**无第三方依赖**。
- 新增 `docs/system/workspace/scripts/quality/config_schema.py` 单一校验真源：`tomllib` 读配置、逐行扫描定位 `file:line`、严格判定类型（bool 不能当 int），报告类型不符 / 未知键 / 未知 section / 必填缺失；rc 0=ok / 1=findings / 2=环境不可用（fail-closed）。
- `runtime/freely` 的 `cmd_doctor` 调用该校验器一次，输出 `config_schema: ok|INVALID|UNAVAILABLE` 与带行号的诊断；**不改变 doctor 既有退出码契约**。
- `package-allowlist.txt` 增 `contracts/`，保证安装态 doctor 找得到契约。
- 现场修正主仓与本工位的 gitignored `.freely/config.toml`：`allowed_paths` 由 `"['templates/']"` 字符串改为与模板一致的 8 项 list。

## 不退化边界

- `docs/system/workspace/scripts/quality/governance-merge-gate` **逐字节未改**（sha256 `ffa2b29f…` 前后一致）；gate 的豁免判定语义不变。
- `templates/config.toml.example` **逐字节未改**——模板本来就是 list，issue 的「修正模板」是事实偏差。
- `cmd_doctor` 既有 5 类检查项数量、顺序、退出语义不变，只在最前面新增一段诊断。
- 未合并角色配置双真相（#4172）、未把 `allowed_paths` 的 gate 消费端改 fail-closed（#4157 族）。
