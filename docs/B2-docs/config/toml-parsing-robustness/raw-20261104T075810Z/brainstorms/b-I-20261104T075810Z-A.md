# B2 Brainstorm: I-20261104T075810Z-A
- issue_id: I-20261104T075810Z-A

## 实现分析
- 契约文件位置：`contracts/config/schema.yaml`（issue 指定），以 JSON 兼容 YAML 子集书写，stdlib `json.loads` 与 `yaml.safe_load` 双可读。
- 校验器：`docs/system/workspace/scripts/quality/config_schema.py`，用 `tomllib` 读配置、逐行扫描定位 `file:line`、按声明类型严格判定（bool 不能当 int）。
- doctor：`cmd_doctor` 在 resolve project 后调用校验器一次，输出 `config_schema: ok/INVALID/UNAVAILABLE`，不 `exit`。
- 打包：`package-allowlist.txt` 加 `contracts/`。
- 现场：主仓与工位的 gitignored `.freely/config.toml` 字符串写法改 list。

## 替代方案评估
| 方案 | 结论 |
|---|---|
| PyYAML + 完整 YAML | 否决：安装态不保证有依赖，缺依赖即静默跳过 |
| 把校验逻辑直接写进 doctor | 否决：会产生第二份判定，且无法被 CI 单独调用 |
| gate 改为 fail-closed | 否决：改变豁免语义且自锁每轮 PR（R8） |
| doctor 因配置错退出 1 | 否决：历史本地配置会让每轮门禁自锁 |
| 校验 `${VAR:-...}` 运行时变量 | 否决：非 config.toml 范畴，另行立项 |

## 不退化边界
- `governance-merge-gate` 逐字节不动。
- `templates/config.toml.example` 逐字节不动（已是正确 list）。
- `cmd_doctor` 既有检查项数量、顺序、退出语义不变，只在最前面加一段诊断。
- schema 缺失/不可解析时校验器 rc=2（fail-closed），不静默跳过。
