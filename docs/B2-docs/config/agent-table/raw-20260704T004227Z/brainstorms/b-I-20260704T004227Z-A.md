### Fix 1: monitor-ai-acp.sh `_bridge_ensure_running` 对齐 freely

#### 1a: tool name 对比用 base_tool

**当前代码** (monitor-ai-acp.sh:70-72):
```bash
last_tool=$(cat "$tool_file" 2>/dev/null || true)
if [[ -z "$tool" || "$last_tool" == "$tool" ]]; then
    return 0
fi
```

问题: `$last_tool` = "opencode-apikey-ds-flash-auto" (freely 写全名), `$tool` = "opencode" (freely 传 base_tool)。永远不匹配 → 误杀。

修复: 两边都提取 base_tool 再比较。
```bash
local last_base="${last_tool%%-*}"
local cur_base="${tool%%-*}"
if [[ -z "$cur_base" || "$last_base" == "$cur_base" ]]; then
    return 0
fi
```

#### 1b: 传 `--acp-bin` + `--acp-args`

**当前代码** (monitor-ai-acp.sh:152):
```bash
python3 "$bridge_script" start --project "$project" >/dev/null 2>&1 || {
```

**修复**: 对齐 `_ensure_acp_bridge_running` 的三层解析：
1. registry → `acp.binary` + `acp.args`
2. config.toml → `FREELY_ACP_{TOOL}_BIN`
3. fallback → `command -v` / default

```bash
local base_tool="${tool%%-*}"
local acp_bin; acp_bin="$(_tool_registry_get "$base_tool" "acp.binary" 2>/dev/null || echo "claude-agent-acp")"
local raw_args; raw_args="$(_tool_registry_get "$base_tool" "acp.args" 2>/dev/null || true)"
local -a acp_args=()
[[ -n "$raw_args" ]] && read -ra acp_args <<<"$raw_args"

# config.toml path (优先)
local config_key; config_key="FREELY_ACP_$(echo "$base_tool" | tr '[:lower:]' '[:upper:]')_BIN"
local config_path; config_path=$(awk -F'"' -v k="$config_key" '$1 == k " =" {print $2; exit}' "$project/.freely/config.toml" 2>/dev/null || true)
[[ -n "$config_path" && -x "$config_path" ]] && acp_bin="$config_path"

python3 "$bridge_script" start --project "$project" --acp-bin "$acp_bin" \
  ${acp_args:+--acp-args "${acp_args[*]}"} --foreground >/dev/null 2>&1
```

### Fix 3: agent-id grep 精确匹配

**当前代码** (freely line 4278):
```bash
_my_id=$(grep -F "$(pwd)" "$_agent_env" 2>/dev/null | grep -oE '(manager_[0-9]+|worker_[0-9]+)' | head -1 || true)
```

修复: 在路径后加 `=` 限定行尾:
```bash
_my_id=$(grep -F "$(pwd)=" "$_agent_env" 2>/dev/null | grep -oE '(manager_[0-9]+|worker_[0-9]+)' | head -1 || true)
```

agent-id.env 格式: `/path/to/worktree=worker=worker_01` → `$(pwd)=` 锚定到 `=` 分隔符, 避免子串误匹配。

同样修复 `_init_agent_table_slot_pin` (line 4779) 中的同样 grep。
