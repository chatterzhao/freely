## 根因

与文案面**完全独立**的第二个缺陷。链路逐层核实：

1. `wt-create:1002` 用 `( cd "$fix_target" && _pull_raw_issue ... )` 进入 **dev 工位**；
2. `_pull_raw_issue`（`wt-create:519-526`）调 `"$ROOT_DIR/bin/raw-issue-pull"`，
   `$ROOT_DIR` 是**主仓**（脚本所在仓库），不是 cwd；
3. `bin/raw-issue-pull:53`
   `ROOT_DIR="${PROJECT_ROOT:-$(cd "$(dirname "${BASH_SOURCE[0]}")/.." && pwd -P)}"`
   → 未设 `PROJECT_ROOT` 时回落**主仓**；
4. `bin/raw-issue-pull:133` 调 `"$ROOT_DIR/bin/issue-sync" create "$local_id"`，
   **未传 `--project`**；
5. `bin/issue-sync:36` ROOT_DIR 同样从脚本位置推导 → `:117`
   `git -C "$ROOT_DIR" rev-parse --abbrev-ref HEAD` → `develop` → guard 命中 → exit 1；
6. `raw-issue-pull:134` 打印 WARN。

即 **cwd 已在合法 dev 工位，但整条链路用「脚本物理位置」而非「调用方工作目录」
判定分支**，必然撞主仓 develop guard。`issue-sync:116` 的注释本身就写明了正解
（`Callers on develop must use: issue-sync --project /path/to/worktree`），
只是调用方没照做。

**后果不止刷屏**：`issue-sync create` 失败意味着 platform title 归一化与
platform_ids 补全被跳过（WARN 原文 "platform title normalization may be
incomplete"），属真实功能缺失。

## 修复方案

1. `bin/raw-issue-pull` 调 `issue-sync create` 时显式传 `--project "$caller_root"`，
   其中 `caller_root` 由调用方 cwd（`$(pwd)`，`wt-create` 已 cd 进 dev 工位）推导，
   不再依赖脚本物理位置。保留 `PROJECT_ROOT` 显式覆盖的既有语义。
2. 不改 `issue-sync` 的 ROOT_DIR 默认推导（被 14 个 `issue-sync.d/*` 模块与
   `_issue_sync_rebind_paths` 依赖，blast radius 过大）。
3. 不改 `wt-create` 的 cd 逻辑，不放宽 protected guard。
4. AT-002：静态断言显式传参 + **真实新建一次 fix 工位**的行为断言
   （输出无 ERROR/WARN）+ 反向验证（主仓 develop 上直接调 `issue-sync create`
   仍必须 exit 1，证明 guard 未被削弱）。

## 验收标准

- RED：develop `91473740c` 基线真实执行 `wt-create --source platform --kind fix`，
  输出含 `[ERROR] issue-sync refuses to run on protected branch: develop` 与
  `[WARN] raw-issue-pull: issue-sync create failed`。
- GREEN：真实新建一次 fix 工位，输出**不含**上述两条，raw issue 正常物化。
- GREEN：主仓 develop 上直接调 `issue-sync create` 仍 exit 1（guard 未削弱）。
- 不退化：`raw-issue-pull` 的 exit 0/3/1 语义与 STDOUT 单 JSON 契约不变；
  `issue-sync` ROOT_DIR 默认推导不变；`wt-create` cd 逻辑不变。

## 刻意不做

- 不改 `issue-sync` 的 ROOT_DIR 默认值（影响全部调用方）。
- 不在 develop 上跳过 `issue-sync create`（会把功能缺口变成静默行为）。
- 不把 protected guard 降级为 WARN（削弱门禁，违反铁律）。
