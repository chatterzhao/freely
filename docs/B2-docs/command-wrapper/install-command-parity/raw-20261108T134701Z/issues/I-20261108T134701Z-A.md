# I-20261108T134701Z-A: 入口命令名与 dispatcher 对齐

## 背景
`bin/freely` 头部注释承诺 `freely install` 会自动移除 `@freely-dev-path` 标记，但 runtime 无 `install` 分派，全仓无安装包脚本。用户按注释抄命令必然失败。

## 目标
1. 删除不存在的命令承诺，安装态入口只指向真实存在的 `freely-package --activate` / `bin/install-state-check`。
2. 新增静态契约检查：入口注释与 `commands.md` 承诺的 `freely <cmd>` 必须存在于 dispatcher 或 `bin/`。
3. 不新增 runtime 分派，保持 27166 行预算。

## 非目标
- 不实现 `freely install` 或 zshrc 标记增删。
- 不改 `freely-package` 行为、不改平台写通道。

## 验收
- AT-001：RED 证明 baseline 存在未实现命令名；GREEN 证明契约检查通过且反例被抓出。
- 全量 CI 保持通过。
