## 实现

- `sync/platform-adapter.py` 的 `GitHubHandler`：新增 `_label_names()` 与 `ensure_github_labels()`；`create_issue()` 在首次失败且错误同时含 `not found` / `label` 时，补齐缺失标签并**重试一次**；其他错误原样返回，重试有界。
- 健康路径零额外 API 调用；Gitee handler 未改。

## 不退化边界

- 不带 labels 的旧调用逐字节等价；`create_issue()` 4 参兼容与 CLI 第 5 参未动；R15 的 severity 数据链未改。
- 不掩盖 auth / permission / network 失败。

## 验收

AT-001 develop 基线快照 RED `7 ok / 12 failed` → 工位 GREEN `19 ok / 0 failed`；16 个相关回归 worktree/baseline 退出码全 MATCH；真机：补标签后 `freely feedback create` 双平台 created（本条 #4230 / IKTSSM 即证据）。
