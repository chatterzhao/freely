## 实现

- 新增 `quality/test-evidence.py` 单一真源：`write`（原子写 8 字段：命令、真实退出码、证据文件、sha256、HEAD）、`validate`（字段齐全/rc=0/hash 匹配/HEAD 一致/时间非 1970）、`manifest-add`。
- `runtime/freely`：新增 `freely test-gate run`（在 test 工位真实执行命令、输出落到 `.freely/run/test-evidence.log`、记录真实 rc，rc=0 才 completed）与 `freely evidence add`（`git add -f` + 记录 hash）；接入 dispatcher 与 usage。旧 `test-gate record` 保留但写出的是无机器证明的 legacy 格式，门禁不再信任。
- `quality/pretests-retirement-gate`：freshness 检查后调用 `test-evidence.py validate`，缺 helper 也 fail-closed；手写三行 env 被明确拒绝。
- 新增 `bin/test-all`：白名单（本地 9 / `--ci` 5 / `--extended` 加 5 个 bash 集成）+ 明确 known-broken 清单（575 个未 onboarding）。
- `.gitee-ci.yml`：删除固定成功行、加入 `fix/*`、跑 `bin/test-all --ci`；`.github/workflows/pr-merge-guard.yml`：新增真实 `run:` verify job。

## 不退化边界

- `test-gate record` 的写入行为与 dispatcher 兼容未改；`pretests-retirement-gate` 的 closeout / issue 解析逻辑未改，只在 freshness 之后新增一道证据校验。
- 未批量执行 575 个未 onboarding 测试；不修改任何平台 issue 生命周期语义。

## 验收

AT-001 develop 基线快照 RED `4 ok / 16 failed` → 工位 GREEN `20 ok / 0 failed`；17 个相关回归 worktree/baseline 退出码对比；真机：本轮收口用 `freely test-gate run` 写入合法证据后门禁放行。
