## 实现

- 新增 `quality/install_state.py` 作为唯一真源：`write_manifest` / `read_manifest` / `head_of` / `packaged_from` / `latest_target` / `check_state` / `activate`；新增薄 CLI `quality/install-state-check.py`（doctor 入口）。
- `bin/freely-package`：`--version auto`、`--activate`、`--home`、`--bin`；打包校验成功后写 `.freely_hashes` 关键文件 sha256 清单；`--activate` 原子替换 `latest` 并只修复悬空/缺失的 PATH 链接；同一 HEAD 已激活时幂等退出，不重复建版本。
- `worktree/pr-merge-guarded`：develop 推送成功后调用 `freely-package --version auto --activate`（失败只告警，不回滚已完成合并）。
- `runtime/freely cmd_doctor`：调用 `install-state-check.py`，打印 `install_state: ok` 或完整诊断 + 修复指令。

## 不退化边界

- 默认打包（不带 `--activate`）行为不变，仍只产出版本目录；`latest` 与 PATH 链接只在显式激活时变更。
- 已存在且有效的 PATH 链接（含指向项目真源的开发态）不会被覆盖。
- 不改任何平台 issue、不改门禁判定、不改 raw 生命周期。
- 全部行为测试使用临时 `FREELY_HOME` 与临时 git 项目树，不触碰真实 `~/.freely` / `~/.local/bin`。

## 验收

AT-001 develop 基线快照 RED `2 ok / 21 failed` → 工位 GREEN `23 ok / 0 failed`；21 个相关回归 worktree/baseline 退出码对比全 MATCH。
