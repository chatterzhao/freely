## 实现

1. 6 个 `.githooks/` shim `-x`→`-f`、末尾 `exit 0`→诊断 + `exit 2`；`post-checkout` 不变。
2. `pre-commit.sh`：hooksPath 不符 exit 2、helper 缺失按自举/外部分流、门禁真身守卫 `-f` + 缺失 exit 2、接入 `check-file-size --staged-only`。
3. `pr-create-guarded` 4 处 skipping → `[ERROR]` + exit 2；正常无 raw key 路径保持。
4. `checkpoint-guard` 默认 `FAIL_ON_REQUIRED=1`。
5. `check-file-size` 新增 `--staged-only` + 全量扫描覆盖无扩展名脚本。
6. 新增 `test-gate-fail-closed`（28 项）。

## 不退化边界

`post-checkout` 逐字节不变；外部项目合法早退保留；正常无 raw key 路径保留；file-size 历史遗留不自锁；`.githooks/bin/git` 不接线；R11/#4149、#4151 未夹带。
