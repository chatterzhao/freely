## 根因

`test-contract-single-source.py` 的 `registry_checks()` 把「本机安装了 cline」当成
未声明的隐含前提：`bin/deploy-skills:77-98` 用 registry 里 `test_command` 的首词做
`command -v` 判定 installed，本机无 cline → `--dry-run` 只输出 claude →
测试第 143-149 行把「输出含 cline」当作 registry 被读取的证据 → 断言绑定机器状态。
结果是 `bin/test-all --ci` 恒 `20 ok / 1 failed`，`freely test-gate run` 无法
`TEST_STATUS=completed`，`pretests-retirement-gate` / `wt-close` 拦截，
**所有后续 issue 都收不了口**。产品侧「只部署已安装工具」是正确语义，缺陷在测试。

已在 develop 基线 `27e91e50c` 与 R33 分支 `92052ebf8` 双跑证伪「本轮引入」；
临时 stub 补齐前提后两者同为 `13 ok / 0 failed`，证明补的是环境前提而非放松判据。

## 修复方案

1. 只改 `docs/system/workspace/scripts/tests/test-contract-single-source.py`：
   在 `registry_checks()` 内用 `tempfile.TemporaryDirectory()` 自建一个可执行的
   `cline` stub，构造 `env = dict(os.environ)` + `PATH = stub + os.pathsep + 原 PATH`，
   传给 present / missing / explicit 三个 `subprocess.run(..., env=env)`。
   stub 生命周期限于测试进程，不写仓库、不改全局 `os.environ`、不含机器绝对路径。
2. 保留 `registry missing: deploy-skills fails closed` 与
   `explicit --tools still works` 两条行为断言不变。
3. 新增 AT-001：静态（自建 stub / 注入 env / 无硬编码路径 / 不改全局 env /
   两条行为断言仍在 / 产品代码与 CI_CORE 不退化 / AT 进双数组 / epics story）、
   行为（**干净 PATH 不带任何外部 shim** 下该测试 13/0、`test-all --ci` 22/0、
   负向控制：改掉 registry 的 cline 首词后断言仍判红）。
4. `bin/test-all` 的 `CORE` 与 `CI_CORE` 各加一行 AT；epics 注册
   `gate/ci-machine-independence` story 并同步 `docs/epics-map.svg`。

## 验收标准

- RED：develop `e003532b5` 基线 + 最终版 AT-001 → `0 ok / N failed`（测试源码无自建 stub，
  干净 PATH 下 `test-contract-single-source.py` 判红，`test-all --ci` 判红）。
- GREEN：AT-001 全绿；干净 PATH 下 `test-contract-single-source.py` → `13 ok / 0 failed`；
  `bin/test-all --ci` → `22 ok / 0 failed`。
- GREEN：`freely test-gate run` **不带外部 shim** → `TEST_STATUS=completed` / `TEST_EXIT_CODE=0`。
- 不退化：`bin/deploy-skills` 与 develop 基线字节一致；`CI_CORE` 未删项；
  其余既有 AT 全绿；`check-runtime-size` / `check-bin-projection` / `check-epics-map` 仍 ok。

## 刻意不做

- 不改 `bin/deploy-skills` 的 installed 判据（产品语义正确）。
- 不改 `CI_CORE` 既有成员、不标 known-broken、不上调任何预算。
- 不把「CI 预装 cline」或「人工 PATH shim」制度化（R33 的 shim 只是一次性应急）。
- 不实现 B1 Option B（重做 deploy-skills 可观测性），改动面会扩散到产品代码。
