## 实现

改动真源为 `docs/system/workspace/scripts/quality/pretests-gate`（`bin/pretests-gate` 只是转发 shim，不修改）。

1. 新增 `_field_line_value(text, key) -> (present, value)`：用 `^- key:[ \t]*(.*)$` 取该行剩余全部内容，仅剥离首尾成对的同型引号，保留 #3957 的裸值 / 单引号 / 双引号 / 反引号四格式兼容。
2. `phase_state()`、`parse_issue_binding()`、`derive_tasks_path()` 改为复用该真源。
3. `parse_fields()` 的 14 个键全部改用该真源，并以 `present and value` 判定收录，根除空值跨行吞掉下一行的静默错读。
4. `parse_scalar()` 改用该真源，补齐单引号 / 双引号写法（此前仅支持裸值与反引号）。
5. `has_blocker_taxonomy()` 合并为一次 `present` 判定，保留「空值行也算字段存在」的 legacy 语义。
6. `issue_is_follow_on()` 改为 `present and value`，保留「空值不算 follow-on」的语义。
7. 新增脚本级回归测试 `docs/system/workspace/scripts/tests/test-pretests-gate-inline-code-fields`，含 `unit` 与 `e2e` 两组。

## 验收

见 `verification/pre-tests.md` 的 AT-001，以及 `verification/test-evidence/AT-001-RED.log` / `AT-001-GREEN.log`。与 develop HEAD 基线逐项比对，既有门禁测试零新增失败。
