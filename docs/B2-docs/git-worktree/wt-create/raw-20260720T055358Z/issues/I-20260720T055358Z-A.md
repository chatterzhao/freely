# I-20260720T055358Z-A: Prevent wt-create silent exit when issue.md lacks phase_state

## 问题

`docs/system/workspace/scripts/worktree/wt-create` line 311:
```
_phase=$(grep 'phase_state:' "$_issue_file" 2>/dev/null | head -1 | sed 's/.*: *//' | tr -d "'\"")
```
When issue.md has no phase_state field, grep returns exit code 1. With `set -euo pipefail`, this propagates through the pipeline and causes the entire script to exit silently — no error message, no worktree creation.

## 修复

Added `|| true` after the pipeline on line 311:
```
_phase=$(grep 'phase_state:' "$_issue_file" 2>/dev/null | head -1 | sed 's/.*: *//' | tr -d "'\"" || true)
```
