# b-I-C：report/attention 与 prompt manifest

## 问题

A2A 只有 state + 自由文本 summary；没有六态 report、单问题 attention、批量决策、prompt manifest。cache 21 条全 estimated，不能算命中率。

## 方案

- report/attention：新增 `agent_reports` 表，append-only；validation 强制六态/单问题/目标。
- 批量决策：`agent_decisions` 表，trigger_id 幂等，accept/stop/ignore/unavailable + reason。
- manifest：用 `<!-- FREELY_SEGMENT:name -->` 标记；解析段名/bytes/sha256，prefix hash 只覆盖 stable/semi 段。
- 运行时：`run-acp-prompt.py` 记录 manifest；没有 marker 时退化为 `full_prompt`，不伪造 11 段。
- usage/cache：reported/estimated/absent；只有 reported 才算 hit rate。

## 边界

- 不做 Manager 批量路由接线；先提供库/CLI + 测试。
- 不做 prompt 全量重构；只加 marker + 日志。
- 真实 patrol 对照留 test 阶段；B2 只做 fixture 前后对照。
