# b-I-20260807T121205Z-A: a2a-exit raw_key 字段传播

## 研究

- candidate acceptance_criteria 要求：合法 raw_key 发出、缺失 raw_key 拒绝、非 review 转换不变、AT 接线。
- 实现面研究：`a2a_task.py` 是 a2a-exit 的唯一 CLI 入口；`A2AClient.update()` 把 kwargs 原样 PATCH；
  `a2a_server.py` PATCH handler 把 body 中出现的字段并入 SSE `state_update`；
  `watchdog_sse.py:198-229` 消费该事件并在缺 raw_key 时 FAIL-CLOSED。
- 契约锚点：`contracts/coordination/contract.yaml` 的 `source_of_truth.sse_topics`
  指向 watchdog_sse.py / a2a_server.py，二者语义必须一致。

## 替代方案

- watchdog 侧按 task_id 回查 raw_key：引入第二套解析真源，且无法约束其他 SSE 消费者 → 不采用。
- server 侧按 task store 补 raw_key：语义更泛化，但 a2a_server.py 依赖 a2a SDK，AT 不能在裸环境导入；
  且与「调用方声明必填字段」的既有契约重复 → 记为长期架构债，本轮不夹带。

## 方案

生产端最小修复 + fail-closed + AT 钉住字段级判据。测试层级以 end-to-end 为主：
直接驱动真实 `a2a_task.py::_main()` 的 a2a-exit 分支（fake client 替代 socket），
断言 PATCH 字段（即 SSE 事件字段）与拒绝行为；单元层断言辅助函数；
不引入 mock-only 的 ghost pass。
