## 背景

worker 在阶段审查点调用 `a2a-exit --state input-required --reason needs-review:<phase>`，
但更新分支漏传 `raw_key`，SSE 事件无该字段，watchdog 的 reviewer 路由必然 FAIL-CLOSED。

## 目标

1. a2a-exit 更新分支在 needs-review 转换时把 `raw_key` 带入 PATCH（参数优先，任务记录兜底）。
2. 无法解析 raw_key 时 fail-closed：返回 `ok:false` 且不发 PATCH。
3. 非 review 状态转换行为不变；新增 AT 注册进 CORE + CI_CORE。

## 非目标

不改 `watchdog_sse.py` 的 FAIL-CLOSED 判定；不改 `a2a_server.py` 的事件构造；
不新增服务端 raw_key 回查（长期架构债，另行排期）。

## 验收

AT-001：develop 基线 RED，fix 工位 GREEN；同时证明「缺失被拒绝」与「合法被发出」。
