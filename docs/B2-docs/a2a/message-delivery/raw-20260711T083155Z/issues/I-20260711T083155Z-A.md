## 实现

修复 A2A agent 间消息投递断裂，并增加 SQLite 层校验使 AI 写错时获得友好指导。

### 修改文件

1. `docs/system/workspace/scripts/runtime/a2a/a2a_server.py`
   - POST /tasks/{id}/messages: emit SSE message_added after store
   - Return HTTP 422 + fix_hint + example on validation failure

2. `docs/system/workspace/scripts/runtime/freely_db_manager.py`
   - 3 层 SQLite 校验 gate: content 非空 / role 合法 / task 存在
   - 每层返回 {valid, error, fix_hint, example}

3. `docs/system/workspace/scripts/runtime/watchdog_sse.py`
   - `_handle_message_delivery()`: task → agent_working → ACP session/prompt
   - 按 role 路由到正确 bridge (opencode/claude/cline)

4. `docs/system/workspace/scripts/runtime/a2a_task.py`
   - `update_message()` 失败时打印 fix_hint + example 到 stderr
