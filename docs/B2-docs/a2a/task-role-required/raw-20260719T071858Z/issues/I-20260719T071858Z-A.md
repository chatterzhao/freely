# I-20260719T071858Z-A: Manager prompt 模板补 --role worker + a2a_task.py --role 改为 required

## 根因

Manager prompt 模板的 a2a-exit 命令示例缺少 `--role worker`。a2a_task.py `--role` 默认值为 `manager`。Manager AI 按模板调用 → 所有 Worker task agent_id=manager → Runtime 无法发现。

## 修复

1. freely L15528-15544: prompt 模板和示例加 `--role worker`/`--role manager`
2. a2a_task.py L830: `--role` 从 `default="manager"` 改为 `required=True`

1. prompt 模板中 a2a-exit 模板含 `--role worker|manager`
2. 委派 Worker 示例含 `--role worker`
