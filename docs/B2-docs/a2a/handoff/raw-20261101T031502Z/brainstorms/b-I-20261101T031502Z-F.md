# b-I-20261101T031502Z-F：讨论入口

## 问题

scan 只看 open issue + body；`fetch_issue` 的 comments 只有 body；PR review/CI 没有 adapter。主意图要求监控讨论，当前没闭环。

## 方案

- A：扩展 scan 每轮拉全部评论。简单但慢/重复。
- B：webhook/Source。实时但需要公网/签名/重放。
- C（选）：轮询 adapter → `events` 表（event_id unique）→ 权威准入 → scan 读 unread。

## 数据

`event_id/source/source_event_id/thread_key/subject/actor/kind/body_ref/created_at/addressed/strength/dedupe_hash`。

## 边界

- 不在 B1 实现 adapter；B2 用 GitHub 真数据 + Gitee unsupported。
- 不做 webhook；后续可替换 poller。
- 评论全文存 body_ref，prompt 只放 preview。

## 风险

- 平台字段缺失 → actor=unknown，只 observe。
- 轮询重复 → event_id unique。
- 评论量大 → 只取增量 + preview。
