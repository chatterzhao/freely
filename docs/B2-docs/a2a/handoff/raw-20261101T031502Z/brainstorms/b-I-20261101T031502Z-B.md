# b-I-20261101T031502Z-B：ownership/handoff

## 问题

`a2a_tasks` 一行承担 task/执行者/message/verdict；new/fork 不带 message；Reviewer 契约三处矛盾。

## 方案

- 三表：`delegation_tasks`、`handoffs`、`handoff_messages`；append-only。
- Task 状态机 terminal 不可变；ownership lease；handback 一次。
- new/fork 后显式 `session/prompt`；role prompt 随消息注入。
- Reviewer 统一 `a2a-exit --state completed --summary <verdict-json>`；更新 reviewer-agent/watchdog。

## 迁移

`a2a_tasks` 双写/只读兼容；SSE 带 handoff_id/message_id；旧行保留查询。

## 风险

- 双写真相冲突 → 新表为写权威，旧表镜像。
- 角色 prompt 注入不完整 → 先随 message 注入；后续做 preset。
- Reviewer JSON 进 summary → Manager 解析失败要有 fallback。
