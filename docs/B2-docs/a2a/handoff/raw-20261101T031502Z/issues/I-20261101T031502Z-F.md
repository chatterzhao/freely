# I-20261101T031502Z-F: 讨论入口：issue comment / PR review / CI 进入 scan

## Goal

让 scan/Manager 真正看到 issue 评论、PR review、CI 结果与 chat，而不是只看 issue body。事件先归一化、去重、过权威准入，再进入 scan/Manager 输入。

## Scope

- 新增事件存储与归一化（`discussion_events.py` 或等价模块）。
- platform-adapter 增加 comment/review/CI 只读方法（GitHub；Gitee 不支持时返回 `unsupported`）。
- scan 输出 unread event summary；Manager prompt 能看到 thread_key/actor/source。
- 不实现 webhook；先轮询 + event_id 去重。
- 不做完整 A2A 协议；事件只是输入。

## Acceptance

见 `verification/pre-tests.md` 的 C-F items：六类事件 schema、真实 issue/PR/CI fixture、幂等、scan 可见。

## Non-goals

- 不做 IM/Feishu 接入。
- 不做事件溯源重写。
- 不把评论全文塞进 Manager prompt；只给摘要 + body_ref。
