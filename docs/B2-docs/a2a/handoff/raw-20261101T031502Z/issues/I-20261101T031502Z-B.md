把 Task、Handoff、Message 分开；后续消息归 owner，跨工单只能 handback 一次；修复 new/fork 丢 message；统一 Reviewer verdict 契约。

## Scope

- 新表 `delegation_tasks`、`handoffs`、`handoff_messages`（append-only），`a2a_tasks` 只读兼容/双写。
- ownership 五类规则：新请求、活跃 thread、已完成 lease、跨工单、人 stop；Reviewer 3 轮。
- `acp_session_connect` 在 new/fork 后显式发送 task message；role prompt 至少随 message 注入。
- Reviewer verdict 统一为 `a2a-exit --state completed --summary <json>`；更新 agent 文档/watchdog 消息。
