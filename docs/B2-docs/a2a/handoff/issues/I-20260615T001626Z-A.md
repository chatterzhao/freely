# I-20260615T001626Z-A: 移除 A2A 文本 JSON 解析 Fallback (Phase 1+2)

- source_candidate: `docs/pre-brainstorms/20260615T001626Z--a2a-no-fallback/candidates.md`
- pre_tests_path: `docs/epics/a2a-replace-handoff/a2a-no-fallback/verification/pre-tests.md`
- verification_artifact_dir: `docs/epics/a2a-replace-handoff/a2a-no-fallback/code-reviews`

## 问题描述

父 Epic `a2a-replace-handoff` 已完成 A2A 协议替换 Handoff 的核心实现。但当前代码中仍然存在双路径：标准 a2a-exit 路径 + 旧的文本 JSON 解析 fallback 路径。

### 1. 信号文件 WORKERS 字段缺失
- `a2a_task.py` 的 a2a-exit 路径未正确写入 WORKERS 字段到 `last-exit-task.env`
- 导致下游读取 WORKERS 时获取空值

### 2. Prompt 指令不一致
- 部分 prompt 文件仍要求 AI 输出 JSON block 格式（供 tail+regex 解析）
- 部分已迁移到 a2a-exit 指令
- 不一致导致 AI 混淆，输出格式不可预测

### 3. WORKER_STATE_INJECT 含旧指令
- AI 系统 prompt 中的 WORKER_STATE_INJECT 区块仍包含 JSON block 指令
- 导致 AI 持续输出旧格式

## 解决方案

### Phase 1: 修复信号文件 WORKERS 字段

修改 `a2a_task.py` 中 a2a-exit 路径，确保 WORKERS 字段正确写入 `last-exit-task.env`。

### Phase 2: 更新所有 Prompt

将所有 prompt 文件中的 JSON block 指令替换为 a2a-exit 指令：
- `manager-agent.md`
- `worker-agent.md`
- 系统 prompt
- `WORKER_STATE_INJECT`
- repair prompt
- delta prompt

## 验收标准

- a2a_task.py a2a-exit 写入 WORKERS 到 last-exit-task.env
- 所有 prompt 文件中无 JSON block 指令残留
- WORKER_STATE_INJECT 中无 JSON block 指令
- FREELY_A2A_TEXT_PARSING_FALLBACK=1 可恢复旧行为
