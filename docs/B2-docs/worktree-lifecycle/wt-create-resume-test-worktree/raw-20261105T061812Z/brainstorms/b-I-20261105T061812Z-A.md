# Design Brainstorm: I-20261105T061812Z-A

## 决策 1：用 `git worktree list --porcelain` 而不是路径解析函数

`freely_wt_resolve_target_path()` 的语义是「为**即将新建**的工位算目标路径」，目录已存在时会追加 hash 后缀（R4/#4191 的根因）。判定已有工位必须用 git 自己登记的事实来源，因此新增 `_wt_registered_dir()` 直接查询 `git worktree list --porcelain` 并校验 `-d`。

## 决策 2：复用 `test-gate.env` 作初始化完成标记，不新增状态文件

`_init_test_worktree_state()` 在成功末尾写 `test-gate.env`，它天然就是初始化完成标记。新增独立 marker 会引入「两个状态谁是真源」的漂移风险。判定用 `grep -q '^TEST_STATUS='` 而非检查值为 `not_tested`：GREEN 之后值是 `completed`，重跑仍应被识别为已初始化。

## 决策 3：按残留项分别补建，不整条重建

dev 目录缺 → `git worktree add <path> <branch>`（分支已在，**禁止 -b**）；test 目录缺且分支在 → 同样不带 -b；test 分支也不在 → 复用 `_create_worktree`（带 -b）；test 目录在但标记缺 → 只重跑 `_init_test_worktree_state()`。这样正常恢复路径（dev 在、test 分支缺）的行为完全不变。

## 决策 4：不夹带两个邻近缺陷

- R4/#4191：`_update_scan_state` 与摘要仍用 `freely_wt_resolve_target_path`，恢复摘要会打印带后缀路径。本 PR 保持原样，避免扩大改动面。
- #4201：顶层 `return 1` 三处是 RED 期间发现的独立缺陷，已用 `freely feedback` 建 `raw-20261106T084804Z`，本 PR 不修。

## 退化审计方法

4 个既有 wt-create 回归测试，用 `git show HEAD:wt-create` 还原基线后同参数复跑，比对退出码与输出。结果：2 PASS/2 FAIL 在两版完全一致，输出差异仅时间戳 → 0 新增失败。

## 被否决的替代方案

把四态判定与 R4 的路径解析重构合并（越界且会掩盖回归）、把顶层 return 顺手一起修（破坏单 issue 边界）、用 `wt-create` 内部状态文件替代 git 登记（引入新真源）。
