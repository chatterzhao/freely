# I-20261103T063354Z-A: PR 收尾用配置平台名
## 背景
pr-merge 合并成功后，收尾循环把 git remote 名 origin 传给 platform-adapter，输出 `unknown: origin` 伪错误。
## 目标
1. adapter 暴露只读 configured-platforms 动作。
2. pr-merge 收尾循环按配置平台名调用 close-pr，跳过 github。
3. 失败输出结构化告警与可操作命令；不吞错。
## 非目标
不改 close_pr 语义、不改平台写通道、不改 dispatcher。
## 验收
AT-001 RED → GREEN；AT-002 既有 pr-merge 回归全绿。
