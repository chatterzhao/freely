# I-20261126T120834Z-A: 退役门禁删除失效的 freshness check

## 目标
1. 删除退役门禁的 `pretests_stale` 自造判据。
2. 以 `validate --json` 的 `ok` 为唯一新鲜度判据（equivalent 放行、stale 拦截）。
3. 保留 not_tested / evidence_sha256 / pretests-gate 校验，不放宽真代码变更重测要求。

## 非目标
不改 `test-evidence.py` 的判据与 HARD_EXCLUDED；不改 wt-close 其他门禁。

## 验收
