## Goal

`freely comment` 写出平台评论后必须正常退出（rc=0、stderr 无 `unbound variable`），且 ACP worker 通知链路真实可达；不引入第二套根路径变量、不增加 `runtime/freely` 行数。

## 研究结论

- `cmd_comment()` 的 ACP 通知段（`:25093-25110`）两处 `python3 -c` 插值 `${PROJECT_ROOT}`（`:25095`、`:25097`）。
- `PROJECT_ROOT` 只在 `write_supervisor_identity_truth()` 的 heredoc 文本中出现（`:3707`），并在 `:3687` 被显式 `unset`；它不是全局变量。`SELF_ROOT` 在 `:32` 全局定义。
- `runtime/freely` 当前 27166 行，`.size-budget` = 27166；新增 `local PROJECT_ROOT=...` 会触发 `check-runtime-size` fail-closed，且 `split-plan.md:97` 禁止上调预算。
- 因此唯一可行解是同行替换变量引用：`${PROJECT_ROOT}` → `${SELF_ROOT}`，两处、共四个插值点。行数不变，语义不变（项目根路径），`agent_working.agent_list_by_raw_key` 调用签名不变。
