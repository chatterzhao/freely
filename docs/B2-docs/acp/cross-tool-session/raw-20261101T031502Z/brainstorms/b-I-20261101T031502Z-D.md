# b-I-D：角色级 harness

## 问题

`agent-table.toml` 已有 `{role}_slot`，但 `harness-status` 只能全量输出，没有 `--role`/requirements/satisfied；没有安全的 apply 入口。

## 方案

- A：直接让 UI 改 TOML。无校验/备份，拒绝。
- B：只做 `--role` 只读。安全但不闭环。
- C（选）：`harness_config` 归一化 + validate + 原子 apply；`harness-status --role` 只读；CLI 共用。

## 边界

- 只写 `{role}_slot`，不改全局 adapter；混合 adapter 不支持。
- `fork=degraded` 允许但显式 degraded；`--strict` 才失败。
- 运行中 session 不重启，返回 requires_restart。
