# I-20261125T100958Z-A: feedback edit 与 wt-create 解耦

## 背景
feedback edit 无条件要求本地 docs/B1-docs/raw-<key>/issue.md 提取 platform_ids/kind/body 前缀，缺文件即失败；但 feedback create 不生成本地文档（设计如此，本地由 wt-create 物化），导致 create→edit 链断。修改 raw issue 不等于实现它，不应要求先建工位。

## 目标
本地文档缺失时用 platform-adapter search <raw_key> 从平台发现 ids → update-issue；不写本地文件；内容来源仅显式参数（空字段不覆盖）；fail-closed + 双平台汇总。

## 非目标
不改 create 不生成本地文档的设计；不改 wt-create；不改 adapter 底层。

## 验收
AT-001：无本地文件时 edit 成功改平台单、不创建本地文件；只改标题/只改正文互不覆盖；0 匹配 fail-closed。
