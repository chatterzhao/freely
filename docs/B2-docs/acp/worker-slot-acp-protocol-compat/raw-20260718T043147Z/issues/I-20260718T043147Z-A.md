# I-20260718T043147Z-A: 换 Worker slot 修复 ACP initialize 超时

- source_candidate: docs/B1-docs/raw-20260718T043147Z/candidates.md#C-20260718T043147Z-A
- pre_tests_path: docs/B2-docs/acp/worker-slot-acp-protocol-compat/raw-20260718T043147Z/verification/pre-tests.md
- verification_artifact_dir: docs/B2-docs/acp/worker-slot-acp-protocol-compat/raw-20260718T043147Z/code-reviews

## 根因

`opencode acp` 是 HTTP server 模式，`acp-bridge.py` 使用 PTY+stdio JSON-RPC。
协议层不相交 → `initialize` 永远超时 → 所有 worker 无法启动。

## 修复

将 `.freely/agent-table.toml` 的 `worker_slot` 从 `opencode-apikey-ds-flash-auto` 改为 `claude-apikey-ds-pro-auto`。
`claude-agent-acp` 使用 stdio JSON-RPC，与 `acp-bridge.py` 完全兼容。

## 验收标准

1. `agent-table.toml` 的 `worker_slot` = `claude-apikey-ds-pro-auto`
2. daemon 重启后 worker ACP bridge `initialize` 成功（无超时错误）
3. Manager 可以成功委派至少一个 Worker（worker task 从 submitted → working）
