# I-20260701T013527Z-A: 修复 get_config 未定义 → bash indirect expansion

- source_candidate: docs/B1-docs/raw-MIGRATED/candidates.md#C-20260701T013527Z-A
- pre_tests_path: docs/epics/acp-tool-setup/config-reader-fix/raw-20260701T013527Z/verification/pre-tests.md
- verification_artifact_dir: docs/epics/acp-tool-setup/config-reader-fix/raw-20260701T013527Z/code-reviews

## 问题

`docs/system/workspace/scripts/runtime/freely` L14052 调用未定义的 `get_config` 函数，导致 daemon 启动时 ACP bridge 无法从 config.toml 读取已配置的 binary 路径。

## 修复

将 `get_config "$_config_key" ""` 替换为 `${!_config_key:-}`，使用 bash indirect variable expansion 直接读取 load_config 已导出的环境变量。
