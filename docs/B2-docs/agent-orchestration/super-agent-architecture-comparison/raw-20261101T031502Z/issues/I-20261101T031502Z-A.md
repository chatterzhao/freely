# I-20261101T031502Z-A: Super-agent 架构对比研究与协作方向立项

## 目标

交付一份可审计的对比研究：DeepSeek Harness 的 Super-agent 设计（文章 + `dsh-superagent-prototype`）与 Freely 的 agent 协作模型，重点回答角色拓扑、委派/交接、授权、状态、上下文、并发、失败恢复、人机交互七个问题，并把可推进的方向登记为 B1 candidate。

## 范围

- 交付物是研究文档、架构对比图和候选登记，不是运行时实现。
- 对比对象固定为 2026-10-31 的文章主张与 2026-11-01 的原型快照。
- 结论必须区分“文章主张 / 原型实现 / Freely 现状”，不得把愿景当现状。
- 对 Freely 的判断必须落到具体文件或行为，不做性能 benchmark。
