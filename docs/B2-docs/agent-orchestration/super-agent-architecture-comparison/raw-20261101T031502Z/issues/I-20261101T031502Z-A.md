# I-20261101T031502Z-A: Super-agent 对比研究、P0 Harness 探针与协作方向立项

## 目标

交付一份可审计的对比研究：DeepSeek Harness 的 Super-agent 设计（文章 + `dsh-superagent-prototype`）与 Freely 的 agent 协作模型。研究必须同时覆盖“理念”“实现质量”“harness 基座”，并落一个可运行的 P0 切片（`freely harness-status`），把后续方向拆成可执行任务。

## 范围

- 交付物是研究文档、概念对照、两张架构图、候选任务拆分，以及 P0 的 `harness-status` 实现与测试。
- 对比对象固定为 2026-10-31 的文章主张与 2026-11-01 的原型快照。
- 结论必须区分“文章主张 / 原型实现 / Freely 现状”，不得把愿景当现状。
- 必须逐项评估路由、交接、缓存命中等实现机制，而不只比较模块名称。
- 必须建立 Super-agent 全量概念到 Freely 的映射，标出同名不同义与缺口。
- 必须回答 harness 抽象与插件边界：Freely 应用内可切换基座优先，DSH adapter 次之，DSH 插件只做工具外溢。
