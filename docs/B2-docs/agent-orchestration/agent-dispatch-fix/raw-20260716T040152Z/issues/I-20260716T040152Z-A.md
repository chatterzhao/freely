# I-20260716T040152Z-A: Agent 编排链路缺陷修复

- source_candidate: docs/B1-docs/raw-20260716T040152Z/candidates.md#C-20260716T040152Z-A

## Scope

修复 Freely agent 编排链路中的 6 个实现缺陷：

### Phase 1 (本 issue): 紧急修复
1. **Bug 1 (CRITICAL)**: `a2a_task.py` a2a-exit 子命令添加 `--reason` 参数，handler 传递 reason 到 A2A client create/update — 恢复 Reviewer 调度链路
2. **Bug 6 (HIGH)**: 添加端到端集成测试覆盖 Worker→Reviewer dispatch 链路

### Phase 2 (本 issue)
3. **Bug 2 (HIGH)**: `freely-cycle` 移除内联 reviewer 分配逻辑，统一走 `watchdog_sse.py`
4. **Bug 3 (MEDIUM)**: `agent_assign(update_only=True)` 添加 stderr 错误日志
5. **Bug 4 (MEDIUM)**: 创建 `bin/a2a-exit` wrapper
6. **Bug 5 (LOW)**: 统一 `--status`/`--state` 参数命名

## Non-Goals
- 不改变 A2A Server 端 (a2a_server.py 已正确支持 reason)
- 不改变 watchdog_sse.py 路由逻辑 (已正确)
- 不改变 Manager/Worker agent 角色定义

## Pre-Brainstorm Summary

Agent 编排链路中 Worker 完成任务后通过 `a2a-exit --state input-required --reason needs-review:*` 触发 Reviewer 审查。但 `a2a-exit` 子命令缺少 `--reason` 参数 → reason 被 `parse_known_args()` 静默丢弃 → SSE event 无 reason → watchdog 路由到 UNKNOWN → Reviewer 永远不会被调度。
