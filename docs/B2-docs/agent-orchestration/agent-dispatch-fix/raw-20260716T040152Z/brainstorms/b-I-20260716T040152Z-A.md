**改动位置**: `a2a_task.py` 两处:
1. argparse (line ~829): 添加 `p_exit.add_argument("--reason", default="", ...)`
2. handler (line ~1101/1107): `c.create(..., reason=...)` 和 `c.update(..., reason=...)`
