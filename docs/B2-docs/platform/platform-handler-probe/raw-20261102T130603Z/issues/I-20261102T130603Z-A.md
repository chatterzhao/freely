# I-20261102T130603Z-A: 平台 handler 探活缓存、重试与 execute 阶段结构化失败

- source_candidate: docs/B1-docs/raw-20261102T130603Z/candidates.md#C-20261102T130603Z-A
- pre_tests_path: docs/B2-docs/platform/platform-handler-probe/raw-20261102T130603Z/verification/pre-tests.md

## 问题 / 实现 / 边界
- 问题：`_handler_for` 每次网络探活且失败返回 None；`guarded_pr_update` execute 阶段无守卫直接解引用，随机抛 AttributeError；同一流程多次探活约 1.1s/次。
- 实现：成功探活进程内缓存；探活走 `_retry_read` 有界重试；新增 `_ensure_handler`，execute 阶段 None 时返回结构化 error 并阻断，不抛异常。
- 边界：不改平台 handler 逻辑、不改 gate 语义、不改 configured_platforms。

## Tech Stack Review
纯 Python 标准库；复用既有 `_retry_read`。

## Architecture Check
探活成本与失败语义收敛在 adapter 注册层，调用方不重复实现；符合"平台边界由 adapter 适配"。
