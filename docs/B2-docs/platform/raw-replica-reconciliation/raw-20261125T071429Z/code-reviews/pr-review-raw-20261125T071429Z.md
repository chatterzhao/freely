## Decision Note

- decision：新增纯函数 `replica_truth.py` 做读失败的 fail-closed 判据；adapter 加只读 `verify-local-id` 与写 `close-local-id`；wt-close 在 Phase 2.5 按 raw key 枚举全 I-* 逐个取证（raw 本体也取证）；batch/pr-merge 去吞错；create 加平台侧判定。**不清理历史 OPEN 副本、不做硬拦截层**。
- why_this：`platform_state` 是关闭通道写入的缓存，让「写入方」同时当「放行判据」形成自证闭环；唯一可破环的方法是引入独立平台读作为判据，并把关闭范围从 `platform_ids` 映射扩展到真实副本全集。纯函数 + 只读 CLI 保持门禁 write-free。
- alternatives_considered：① 仅校验 `platform_ids` 非空 —— 无法覆盖孤儿/重复副本，否决；② 让 batch 写回真实状态当判据 —— 仍是同一写入方自证，否决；③ 引入硬拦截层（PATH wrapper 拦 gh 直写）—— 属独立 B1/B2 边界，不夹带，否决；④ 手工调 adapter 关孤儿副本 —— 违背吃狗粮原则、产生部分成功（#4678 教训），否决。
- boundary_non_goals：不清理历史 17 个 OPEN 副本；不做硬拦截；不改 `runtime/freely` 行数；#4698（文档漂移）与 #4687（孤儿关闭入口）保持独立 open。
- residual_risk：R2 `_platform_has_open_replica` 把「平台不可读」当「已存在」，create 打印 skip 却写 open；R4 缺 B1/B3 行为级用例；R5 scoped batch 重写 closed raw 的 `updated_at`；R6 每文档 2 次全量列举偏慢；R7 `configured_platforms()` 为空时 `close_local_id` 返回 {} 失败。均为独立改进项，非本轮阻塞。
