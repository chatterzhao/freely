# I-20261127T110239Z-A: 可操作的评论失败诊断
## 背景
Gitee 对 closed Issue 返回裸 401「当前issue已关闭评论功能」，实际原因是仓库 `issue_comment=false`；`promote-finalize` 重跑会重复推评论。
## 目标
1. 评论前检查 Gitee Issue 状态，closed 时跳过并说明真实原因。
2. 401 翻译为可操作诊断。
3. `promote-finalize` 重跑幂等。
## 非目标
不改平台设置、不删除已有评论、不实现单平台裁剪参数。
## 验收
AT RED 2/9 → GREEN 11/0 + unit。
