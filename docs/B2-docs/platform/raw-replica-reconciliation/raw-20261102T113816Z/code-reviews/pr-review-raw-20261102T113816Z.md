3. **重试预算有限**：3 次、退避合计 ≤1.65s；代理重启超过约 3 秒仍落到 degraded。
4. **materialize 未接降级**：`pull_raw_issue` 仍要求全平台 `ok`。该路径没有本地副本可核对，作者认为保持严格是对的，但意味着断网时无法从平台物化——本轮未验证这条限制的实际影响。
5. **owner 自审**：review 与实现同一人，没有独立第三方。四层走查与证据可复核，但不具备独立性。
