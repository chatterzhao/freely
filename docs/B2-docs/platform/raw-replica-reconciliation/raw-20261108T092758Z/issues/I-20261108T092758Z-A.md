## 实现

- 新增纯模块 `docs/system/workspace/scripts/sync/replica_guard.py`：`classify_receipt(receipt, platform) -> (present|absent|indeterminate, issue_id, url)`，只解释 `discover-raw` 的 per-platform receipt，无 I/O/网络。
- `bin/issue-sync` 新增 `_replica_receipt()`（调 `platform-adapter.py discover-raw`）、`_replica_decide()`、`_backfill_close_replicas()`；`cmd_create` 仅当某配置平台本地缺 id 时咨询平台侧：`present`→`_update_platform_ids` 回填不建、`absent`→原建单路径、`indeterminate`→`_failed`（失败关闭，绝不建重复）；`cmd_close` strict 前回填 partial 缓存（仅终态，保 R12 零写入不变量）。

## 不退化边界

- `platform-adapter.py search_raw_issue` 的 `--state all` + 全量分页 + 模糊兜底、`_resolve_raw_identity` 的 fail-closed ambiguous、`close_platforms` 四段式与 0/3/1 退出码、`bin/raw-issue-pull` 全部逐字未改。
- 健康路径（`platform_ids` 已含全部配置平台）零 discover I/O、零建单、零文件改写，行为逐字节不变。
- `kind: linked`/I-* 的 create/close 不受影响（guard 仅对 `raw-*` + `kind: raw` 生效）。
