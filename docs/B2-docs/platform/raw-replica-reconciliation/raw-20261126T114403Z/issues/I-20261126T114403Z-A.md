# I-20261126T114403Z-A: close-orphans 批量模式复用平台读取

## 背景
`close-orphans <local_id>` 每次调用都全量重扫 GitHub+Gitee OPEN issue；48 个 id 的治理清理耗时近一小时，且提高平台抖动命中率。

## 目标
1. 新增 `freely issue-sync close-orphans --all-completed [linked|raw]`。
2. 一次平台读取记录，复用给所有 terminal local_id 的副本判定与关闭。
3. 逐 id 汇总 closed/absent/error，rc 0/3/1 语义保持，失败打印可执行 retry 命令。

## 非目标
- 不改 adapter 的副本判据（仍由 `replica_truth` 决定）；
- 不改本地 frontmatter，不新增平台写通道；
- 不改单 id 入口行为。

## 验收
AT-001：结构断言 + stub adapter 行为断言（平台读取次数 = 1、终态筛选、rc 0/3/1 透传、retry 命令可操作）。
