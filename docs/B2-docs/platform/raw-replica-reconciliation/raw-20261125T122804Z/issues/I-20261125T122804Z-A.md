# I-20261125T122804Z-A: 生成型 updated 行不参与副本内容判定

## 背景
`| updated |` 行由 `platform_body()` 从 frontmatter `updated_at` 生成，而 frontmatter 有多个合法写入者；本地正文表格保留旧值 → raw-reconciliation 永久 `content_diverged`。

## 目标
1. `canonical_projection._body()` 将 `| updated | ... |` 归一化（行必须存在，值不比较）。
2. 其他表格行与人类正文仍严格比较。
3. 不改平台写通道、`platform_body()` 其他字段。

## 非目标
不改 `updated_at` 的写入语义；不覆盖 `created`/`phase_state` 等行的分歧。

## 验收
AT-001：结构断言 + 纯函数行为断言（updated-only 差异 ok；正文差异仍 diverged）。
