1. 新增 `docs/system/workspace/scripts/runtime/raw_title_normalize.py`：`normalize_open_raw_titles()` 从平台 OPEN 记录按 `extract_raw_key(title+body)` 定 key，`canonical_raw_title()` 算应然标题，仅经 adapter `update_issue` 写标题并打印 from→to；幂等、`--dry-run`、失败非零。

3. `pr-create-guarded` Step 0b 增加 preflight：门禁报 `non_canonical_title` 时调用同一规范化入口并复检。
4. `raw-reconciliation-gate` 增加 `non_canonical_title` 结构化诊断；`freely_wt_assert_raw_reconciled_readonly()` 打印精简摘要，完整 receipt 落临时文件。

- 不改 `canonical_raw_title()` / `_resolve_raw_identity()`；不放宽 `ambiguous`。
- 不修 body/comments/labels/本地文档；不追溯历史 CLOSED raw 标题。
