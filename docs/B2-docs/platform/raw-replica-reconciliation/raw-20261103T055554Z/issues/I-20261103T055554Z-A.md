## 问题 / 实现 / 边界
- 问题：`search_raw_issue` 把 title/body 子串都当身份来源，body 交叉引用导致多匹配 ambiguous，`raw-reconciliation-gate` 误伤 block PR。
- 实现：新增 `_resolve_raw_identity(matches, raw_key)` 纯函数：标题前缀唯一命中优先；多条标题命中仍 ambiguous；无标题命中时保留单条 body 兜底。`_discover_one` 与 `_unique_raw_issue` 统一改用它。
- 边界：不改 reconcile/scan 消费逻辑；不改 issue 文本格式。
