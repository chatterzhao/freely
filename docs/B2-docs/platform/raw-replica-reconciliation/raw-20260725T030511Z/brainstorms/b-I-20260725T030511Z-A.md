# B2 Brainstorm: I-20260725T030511Z-A

## Decision

以纯函数 module 承担 canonical projection 和 receipt，不把 domain comparison 再塞进 adapter 或 lifecycle shell。

## Data contract

每个远端副本：

```text
{ platform, remote_id, title, body, state, labels, comments, updated_at, version }
```

每次 gate：

```text
{ raw_key, stage, status, configured_platforms, replicas, differences, observed_at }
```

`status ∈ consistent | blocked | degraded | unknown`。只有 `consistent` 可继续 lifecycle。

## Boundary

resolution 不在本实现切片内；本切片只给其提供可审计的差异输入，并保证 read-only gate 没有隐式同步。
