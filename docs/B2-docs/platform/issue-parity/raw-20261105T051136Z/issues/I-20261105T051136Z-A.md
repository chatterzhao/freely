## 实现

1. 新增 `docs/system/workspace/scripts/sync/raw_title_contract.py`：`canonical_raw_title()` / `is_canonical_raw_title()` / `platform_title()`，作为 adapter、issue-sync、feedback edit 三处的唯一达标真源。
2. `platform-adapter.py.pull_raw_issue()` 保留 `created_at` 反推兼容分支，但推导值只用于诊断；删除 `raw_key = sk` 与 `target_dir` 改写，本地身份锚定调用方 key。
3. 平台标题改用 `canonical_raw_title()` 构造并遍历所有 replica 同步，替换掉 no-op 的 `title.replace(...)`；失败输出 WARNING。
4. `bin/issue-sync._platform_title()` 收敛到 `platform_title()`，linked 及其他 kind 保持历史投影。
5. `runtime/freely.cmd_feedback` edit 对 `kind == raw` 且显式 `--title` 时复用同一规范化，不回写历史标题。
6. `bin/raw-issue-pull` 去掉 `2>/dev/null` 与 `|| true`，改为可诊断告警；`wt-create._pull_raw_issue()` 严格比对 `expected_local_id` 并校验 `expected_issue_file`，失败由既有清理分支移除 dev 工位。
7. 新增 `docs/system/workspace/scripts/tests/test-raw-key-drift`（unit + static + wtcreate 三组）。

## 不退化边界

`cmd_feedback` create 的类型前缀/长度校验、`_resolve_raw_identity()` 单条兜底、`_created_at_to_key()` 兼容分支、`_platform_title()` 自动达标能力均保留；`linked` 分支投影不变；不修 Q3、不改平台读通道与 scan 状态机。
