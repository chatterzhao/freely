## 实现

- `sync/platform-adapter.py` 新增 `severity_from_replicas(readable)`：遍历每个可读平台副本的 `severity/*` 标签，大小写归一，只认 P0/P1/P2；两个不同显式值抛 `ValueError`（fail-closed，不静默猜）；一方缺标签仅打 stderr 告警；无标签返回 None。
- `pull_raw_issue` 调用该解析器，在 strict 与 legacy 两个分支都把结果写成可选第 22 字段 `fm["severity"]`。契约 `raw_metadata_contract` 已支持该形状，无需改动。
- `lifecycle/raw_reconciliation.py::canonical_projection` 移除 `severity/` 排除（保留 `phase/`），让「双平台优先级一致」重新成为可机器证明的事实。
- 新增 `docs/system/workspace/scripts/tests/test-severity-materialization.py`（AT-001，9 项，含真实 `pull_raw_issue` 端到端物化）。

## 不退化边界

- 无 severity 标签的历史 raw 保持 21 字段、零改写（AT 反向断言）。
- 不改 `RAW_METADATA_FIELDS`（severity 仍是可选字段，不变成必需）。
- `phase/*` 仍从副本比较中排除（平台从不更新 phase 快照）。
- 未回填任何历史 raw。
