# I-20260708T122837Z-A: scan stage + batch + derive_action

- source_candidate: `docs/B1-docs/raw-20260708T122837Z/candidates.md`
- pre_tests_path: `docs/B2-docs/ibm/b2-governance/raw-20260708T122837Z/verification/pre-tests.md`
- verification_artifact_dir: `docs/B2-docs/ibm/b2-governance/raw-20260708T122837Z/code-reviews`

## 问题

lifecycle-v3 scan 丢弃了旧 scan 的核心能力：batch 聚合、stage 分级、derive_action。
271 条独立项直注入 prompt，Manager 无法处理。

## 实现

修改 `task-lifecycle-scan.py`：
1. 新增 `_classify_stage()` 和 `_stage_action()` 模块级函数
2. 新增 `_batch_action()` 生成批量操作描述
3. 后处理循环：所有 item 追加 stage + stage_action 字段
4. 按 stage 聚合为 batches（close_platform/close_local → batch，恢复/B1_proposed → individual）
5. 输出新增 `batches` 字段和 `summary.by_stage`

## 验收

- scan 输出每条 item 含 stage + stage_action
- 273 条 → 3 个 batch（close_local 262, close_platform 10, 恢复 1）
- scan_version 保持 lifecycle-v3
