# I-20260708T174039Z-A: tool-launchers socket path 加入 base_tool 后缀

- source_candidate: `docs/B1-docs/raw-20260708T174039Z/candidates.md`
- pre_tests_path: `docs/B2-docs/ibm/b2-governance/raw-20260708T174039Z/verification/pre-tests.md`
- verification_artifact_dir: `docs/B2-docs/ibm/b2-governance/raw-20260708T174039Z/code-reviews`

## 问题

commit 191afb82c 引入了 per-tool ACP bridge socket（带 base_tool 后缀），但 tool-launchers.sh 的 tool_run_acp_from_prompt_file() 调用 _bridge_socket 时未传 base_tool，导致 socket 路径不匹配。

## 实现

修改 `tool_run_acp_from_prompt_file()` 中 `_bridge_socket "$project"` → `_bridge_socket "$project" "$tool"`，其中 `$tool` 已通过 `_resolve_tool_family` 解析为 base family name。

## 验收

- daemon 启动后 cycle log 不再为空
- ACP bridge socket 路径前后一致
