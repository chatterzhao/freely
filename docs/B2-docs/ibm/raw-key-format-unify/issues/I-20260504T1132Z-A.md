## Changes

18 files: regex/glob patterns now accept both old (`YYYYMMDD-HHMM`) and new (`YYYYMMDDTHHMMZ`) raw key formats.
New items use ISO format; historical data stays untouched.

## Implementation Decision Note

- decision: All regex accept both formats via `[-T]` and `Z?` qualifiers
- why_this: ISO 8601 already used by GitHub issue-sync. Dual-compat avoids migration risk
- alternatives_considered: Full migration (rejected), new-only (rejected)
- boundary_non_goals: chat-inbox DB format, git tag format
- residual_risk: External tooling might not parse new format; mitigated by keeping old support
