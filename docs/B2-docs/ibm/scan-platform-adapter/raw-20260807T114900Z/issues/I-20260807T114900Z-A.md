# I-20260807T114900Z-A: task-lifecycle-scan platform_adapter import 断裂修复

- source_candidate: `docs/B1-docs/raw-20260807T114900Z/candidates.md#C-20260807T114900Z-A`
- pre_tests_path: `docs/B2-docs/ibm/scan-platform-adapter/raw-20260807T114900Z/verification/pre-tests.md`
- verification_artifact_dir: `docs/B2-docs/ibm/scan-platform-adapter/raw-20260807T114900Z/code-reviews`

## 背景

`task-lifecycle-scan.py` 三处直接 `from platform_adapter import ...`（原 L451 `configured_platforms`、L502 `list_open_issue_records`、L548 `_handlers`/`_safe`），但模块文件名是 `platform-adapter.py`（连字符，刻意约定避免与 pip 包冲突）。连字符不是合法 Python 标识符，直接 import 必然 ImportError → scan `platform_health: degraded`，87 个 open platform issues 不可见。

## 实现

在 `task-lifecycle-scan.py` 中：
1. 顶部加 `import importlib.util`
2. 新增缓存 `_get_pa(project)` helper：`spec_from_file_location("platform_adapter", <project>/docs/system/workspace/scripts/sync/platform-adapter.py)` + `module_from_spec` + `exec_module`，按 project 缓存
3. L451 `_detect_platforms` → `_get_pa(project).configured_platforms()`
4. L502 `get_platform_open_issues` → `_get_pa(project).list_open_issue_records()`
5. L548 `get_all_platform_issue_states` → `_get_pa(project)._handlers()` / `_get_pa(project)._safe`

先例：orphaned commit `2b2f4c77f`（从未 merge）用同一 importlib 方案，但旧代码基于已重构前的符号（`list_open_issues`/`fetch_issue_state`）与路径（`Path(__file__).parent.parent`），需按当前结构重写。
