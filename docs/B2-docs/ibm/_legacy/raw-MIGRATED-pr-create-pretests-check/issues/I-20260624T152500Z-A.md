# I-20260624T152500Z-A: Add pretests evidence check to pr-create-guarded

## Background

`pr-create-guarded` currently only checks IBM governance docs (Step 2b) but does not verify that pretests execution evidence exists. The pretests check only runs at `wt-close` time, which is too late — by then the code is already merged into develop.

## Scope

Add a Step 2c to `pr-create-guarded` that calls `pretests-retirement-gate` to verify that pretests execution evidence (`.freely/run/workcell-state.env`) exists before allowing PR creation.

## Changes

- `docs/system/workspace/scripts/worktree/pr-create-guarded`: Added Step 2c pretests-retirement-gate call between Step 2b (IBM governance) and the gate-passed marker

## Implementation Decision Note

**Decision**: Use `pretests-retirement-gate` with `--project` and `--worktree-path` flags, matching the exact pattern from `wt-close`. The main project root is resolved via `git worktree list --porcelain` to find the primary worktree.

**Rationale**: Consistency with existing `wt-close` pattern ensures uniform pretests enforcement across the pipeline. Using `git worktree list --porcelain` is robust against worktree vs main repo ambiguity.

**Trade-offs**: Introduces a self-referential gate (the change blocks its own PR if no test evidence exists). This is expected — manual fix contexts should create the evidence file before PR creation.
