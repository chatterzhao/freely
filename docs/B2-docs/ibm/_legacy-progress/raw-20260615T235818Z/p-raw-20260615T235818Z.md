## Changes

### New files
- **`docs/system/workspace/scripts/runtime/freely_config.py`** — Python config module. Uses tomllib (Python 3.11+) for reading. Provides CLI subcommands:
  - `toml2env` — converts config.toml to shell `export` statements (also reads config.env as fallback)
  - `upsert` — modifies a single key in config.toml (also syncs config.env for backward compat)
  - `init-toml` — generates config.toml from key=value pairs
  - `print` — displays config in human-readable form
- **`bin/toml2env`** — thin shell wrapper around `freely_config.py toml2env`

### Modified files
- **`docs/system/workspace/scripts/runtime/freely`**:
  - `config_file()` returns `.freely/config.toml` (was `.freely/config.env`)
  - `env_config_file()` added — returns `.freely/config.env` for backward compat
  - `global_config_file()` returns `config.toml` (was `config.env`)
  - `global_env_config_file()` added for backward compat
  - `source_config()` added — reads config.toml via toml2env, falls back to config.env source
  - `source_global_config()` added — same for global config
  - `load_config()` — tries config.toml first via `source_config()`, falls back to config.env
  - `write_config()` — generates config.toml (TOML format with `key = "value"` syntax), also writes config.env for backward compat
  - `upsert_config_key()` — updates both config.toml (via Python) and config.env (via awk)
  - All `source "$cfg"` calls replaced with `source_config "$project"` or `source_global_config`
  - Hardcoded `.freely/config.env` references updated to `.freely/config.toml`
- **`docs/system/workspace/scripts/runtime/network-proxy-resolver.sh`** — config file functions return TOML paths; read function tries TOML first via toml2env, falls back to env source
- **`docs/system/workspace/scripts/runtime/ai-cli`** — auto-detection checks both `.freely/config.toml` and `.freely/config.env`; AI_TOOL updates use `freely_config.py upsert` (updates TOML + env)
- **`docs/system/workspace/scripts/runtime/signal-intent-handler`** — tries config.toml first, falls back to config.env
- **`docs/system/workspace/scripts/runtime/interruption-manager-handler`** — tries config.toml first via `source_config()`, falls back to config.env
