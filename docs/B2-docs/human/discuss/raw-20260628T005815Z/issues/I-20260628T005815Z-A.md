## 实现范围

### 新建
- `freely comment` 命令 — adapter 直写评论到所有平台
- `freely discuss` 命令 — AI 群聊讨论，新建/继续/归档
- 讨论 agent（agent-table.toml discuss_slot + pool=1）
- 讨论执行 skill：`docs/system/workspace/skills/freely-discuss-execution/SKILL.md`
- 讨论归档 skill：`docs/system/workspace/skills/freely-discuss-archive-execution/SKILL.md`
  - 流程：skill 分析讨论 → 产出评论（`freely comment`）和/或 raw issue（`freely feedback`）→ 插入最后一条讨论消息记录所有产出 ID（comment IDs + raw issue IDs）→ 关闭讨论（本地 platform_state: closed + 平台 Discussions close）
- 数据库：SQLite `discussions` 表（元数据：session_id, owner, status, platform_ids(JSON), created_at, updated_at）+ JSONL `.freely/discussions/{session_id}.jsonl`（消息内容：每行 author/body/refs/created_at/consumed）

- `freely_db_manager.py`：新增 discussion 相关 handler
- `platform-adapter.py`：新增 discussion create/reply/close/get_state
- `agent-table.toml`：新增 discuss agent 配置

  [[agents]]

- `wt-close`：Phase 0 评论 resolution 检查
