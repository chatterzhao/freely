# I-20260629T132042Z-A: replace ./bin/ with freely in hook scripts and start-lead-agent

- source_candidate: docs/B1-docs/raw-20260629T132042Z42Z/candidates.md#C-20260629T132042Z-A

## 实现概述

6 个 .sh 文件中的 `./bin/` CLI 命令引用替换为 `freely` 子命令格式：

| 文件 | 角色 |
|------|------|
| `.githooks/pre-commit.sh` | 提交前钩子（开发工位副本） |
| `docs/system/workspace/hooks/pre-commit.sh` | 提交前钩子（正式真源） |
| `docs/system/workspace/hooks/pre-merge-commit.sh` | 合并提交钩子 |
| `docs/system/workspace/hooks/pre-push.sh` | 推送前钩子 |
| `docs/system/workspace/hooks/reference-transaction.sh` | 引用事务钩子 |
| `docs/system/workspace/scripts/start-lead-agent.sh` | lead-agent 启动脚本 |

## 替换规则

| 原始模式 | 替换为 | 类别 |
|----------|--------|------|
| `./bin/freely xxx` | `freely xxx` | CLI 命令 |
| `./bin/pr-create-guarded` / `./bin/pr-merge-guarded` | `freely pr-create-guarded` / `freely pr-merge-guarded` | CLI 命令 |
| `./bin/wt-create` / `./bin/wt-close` | `freely wt-create` / `freely wt-close` | CLI 命令 |
| `./bin/governance-merge-gate` / `./bin/governance-promotion-gate` | `freely governance-merge-gate` / `freely governance-promotion-gate` | CLI 命令 |
| `./bin/checkpoint-guard` | `freely checkpoint-guard` | CLI 命令 |
| `./bin/pretests-gate` | `freely pretests-gate` | CLI 命令 |
| `[[ -x "./bin/governance-merge-gate" ]]` 等 | `which freely >/dev/null 2>&1` | 可用性检查 |
| `source ./bin/worktree-common.sh` | 保留不变 | 库引用（非 CLI） |
| `[[ -f "./bin/worktree-common.sh" ]]` | 保留不变 | 库文件存在性检查 |
| 提示消息中的 `./bin/xxx` | `freely xxx` | 用户面向文本 |

## 边界

- `worktree-common.sh` 是 shell 库，不属于 CLI 命令迁移范围
- `.githooks/pre-commit.sh` 是 `docs/system/workspace/hooks/pre-commit.sh` 的副本，需同时更新
- hook 脚本中引用 `freely` 依赖 PATH 环境变量正确配置（`freely` 在 PATH 中）
