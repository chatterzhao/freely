# I-20260705T061416Z-A: fix dirty 提示 backtick 命令替换

- source_candidate: docs/B1-docs/raw-20260705T061416Z/candidates.md#C-20260705T061416Z-A
- verification_artifact_dir: docs/B2-docs/runtime/runtime-startup-authority-and-readiness-governance/raw-20260705T061416Z/code-reviews
- pre_tests_path: docs/B2-docs/runtime/runtime-startup-authority-and-readiness-governance/raw-20260705T061416Z/verification/pre-tests.md

## 背景

GitHub issue #3742 报告两个 bug：
1. daemon 启动时 `__manager__` 行用 `agent_assign` 无 slot → slot 列永远为空
2. dirty 提示中 `freely-workflow-guarded-execution` 的 backtick 被 bash 当命令执行

Bug 1 已在 M-20260703T080443Z-A 中通过改用 `acp_session_register` + `slot` 修复。

Bug 2 是本次修复目标：`docs/system/workspace/scripts/runtime/freely:21982` 行中，双引号内 `\\` + 裸反引号 导致 bash 将 skill 名当作命令执行。

## 实现

修改 `docs/system/workspace/scripts/runtime/freely:21982`：

```diff
-      log_error "    详细流程见 skill \\`freely-workflow-guarded-execution\\`"
+      log_error "    详细流程见 skill freely-workflow-guarded-execution"
```

根因：`log_error()` 定义为 `echo "$*"`。双引号字符串中 `\\` → 字面 `\`，紧接着裸反引号 `` ` `` 触发命令替换。去掉反引号，纯文本输出 skill 名称。
