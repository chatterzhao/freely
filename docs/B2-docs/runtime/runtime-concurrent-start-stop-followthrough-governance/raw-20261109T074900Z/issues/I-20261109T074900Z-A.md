## 实现

- `runtime/freely` 新增单一 helper `freely_escape_regex()`：`python3 - "$1" <<'PY'` + `re.escape(sys.argv[1])`，沿用 R22 的 argv 安全形式，不引入 `python3 -c` 插值。
- `:9007` 与 `:22349` 两处 `pkill -f "python3.*a2a_server\.py.*--project.*${project}.*--start"` 改为先算 `local _project_re="$(freely_escape_regex "$project")" || return 1`，再拼 `${_project_re}`；正则其余部分逐字不动。
- 新增 `scripts/tests/test-pkill-project-escape.py`（AT-001，12 项，含真实 `pgrep -f` 反向 PoC）。

## 不退化边界

- 另 3 处固定 pattern pkill（:14886 / :22394 / :22432）逐字未改 —— 它们不含外部项目路径。
- `|| true` 清理语义、`2>/dev/null`、正则中的其它字面量全部不变。
- 未做派发 CAS、SSE 实例收敛（拆 #4254）、未改启动锁与 DB 单实例（#4155 已完成）。

## 验收

AT-001 develop 基线 RED `5 ok / 7 failed` → 工位 GREEN `12 ok / 0 failed`。真实 `pgrep -f` 起两个带标记子进程验证：未转义 pattern 命中 ≥2 个（误杀），转义后只命中 1 个；同时断言转义后仍匹配自己的项目。5 个相关回归基线对比 0 新增失败。
