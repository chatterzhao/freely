## 改动

1. `docs/system/workspace/scripts/runtime/freely` — `stop_project_runtime()` 中，获取锁之前先调用 `cleanup_project_start_lock_if_stale_for_runtime`

## 根因

force-kill daemon 后 `project-start.lock` 残留，导致 daemon stop 获取锁失败。"start already in progress" 误报。

## 验证

- daemon start → force kill → daemon stop 不阻塞
- daemon 正常 stop 流程不受影响
- daemon 全链路验证通过：scan → delegate → worker → cleanup → next
