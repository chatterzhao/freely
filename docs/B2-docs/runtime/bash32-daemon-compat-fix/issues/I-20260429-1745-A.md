## 问题

Freely runtime 在 macOS bash 3.2 上有两个兼容性 bug 导致 daemon 无法正常工作：
1. daemon 进程通过 `discover_supervisor_pid` 自检测后自杀
2. `select_launch_kind` 中 `ls` 空 glob + `pipefail` 导致 shell 崩溃

## 修复

`docs/system/workspace/scripts/runtime/freely` — 两处改动：

### `resolve_active_supervisor_pid_for_start`
- 显式追加 `$$` 到 excluded_pids
- 跳过指向自己的 `supervisor.pid` 文件

### `select_launch_kind` ACP resume detection
- 用 `shopt -s nullglob` + 数组检查代替裸 `ls` 管道
- 仅在 glob 匹配到文件时才执行 `ls`
