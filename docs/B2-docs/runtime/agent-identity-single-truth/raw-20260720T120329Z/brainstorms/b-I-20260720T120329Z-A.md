## Implementation Analysis

### F1: 新增 reviews 表 (freely_db_manager.py `_ensure_tables`)

当前无 reviews 表。需新增：

```sql
CREATE TABLE IF NOT EXISTS reviews (
    id INTEGER PRIMARY KEY AUTOINCREMENT,
    raw_key TEXT NOT NULL,
    review_stage TEXT NOT NULL,   -- b1|b2|red|dev|green
    verdict TEXT NOT NULL,         -- PASS|FAIL
    reviewed_by TEXT NOT NULL,     -- "reviewer_07:codex"
    reviewed_at TEXT NOT NULL DEFAULT (datetime('now')),
    findings TEXT DEFAULT '[]',   -- JSON array
    UNIQUE(raw_key, review_stage) -- one verdict per stage per raw_key
)
CREATE INDEX IF NOT EXISTS idx_reviews_raw_key ON reviews(raw_key)
```

### F2: record_review RPC handler (freely_db_manager.py)

```python
@_h("agent_working.record_review")
def h_aw_record_review(daemon: DbDaemon, params: dict) -> dict:
    """Persist review verdict. UPSERT by (raw_key, review_stage)."""
    daemon.conn.execute("""
        INSERT INTO reviews (raw_key, review_stage, verdict, reviewed_by, reviewed_at, findings)
        VALUES (?,?,?,?,datetime('now'),?)
        ON CONFLICT(raw_key, review_stage) DO UPDATE SET
            verdict=excluded.verdict,
            reviewed_by=excluded.reviewed_by,
            reviewed_at=datetime('now'),
            findings=excluded.findings
    """, (params["raw_key"], params["review_stage"], params["verdict"],
          params["reviewed_by"], params.get("findings","[]")))
    daemon.conn.commit()
    return {"status": "ok", "raw_key": params["raw_key"], "review_stage": params["review_stage"]}
```

### F3: get_reviews RPC handler (freely_db_manager.py)

```python
@_h("agent_working.get_reviews")
def h_aw_get_reviews(daemon: DbDaemon, params: dict) -> dict:
    """Return all review records for a raw_key as {stage: {verdict, ...}}."""
    rows = daemon.conn.execute(
        "SELECT * FROM reviews WHERE raw_key=? ORDER BY review_stage",
        (params["raw_key"],)
    ).fetchall()
    reviews = {}
    for r in rows:
        reviews[r["review_stage"]] = {
            "verdict": r["verdict"],
            "reviewed_by": r["reviewed_by"],
            "reviewed_at": r["reviewed_at"],
            "findings": r["findings"],
        }
    return {"reviews": reviews}
```

### F4: agent_next_free 切换到原子分配 (agent_working.py L251-258)

当前：
```python
def agent_next_free(project, role, pool_size):
    result = _db_rpc(project, "agent_working.next_free", ...)
    return result.get("agent_id")
```

`next_free` 只查询不分配。调用方 `agent_next_free` + `agent_assign` 两次 RPC 间存在 TOCTOU 窗口。

修复：改为调用 `next_free_and_assign`（单次原子 RPC）：

```python
def agent_next_free(project, role, pool_size, raw_key=None):
    if raw_key:
        # Use atomic next_free_and_assign when raw_key is available
        result = _db_rpc(project, "agent_working.next_free_and_assign", {
            "role": role, "pool_size": str(pool_size), "raw_key": raw_key
        })
        return result.get("agent_id") if result.get("assigned") else None
    # Fallback: non-atomic query-only (for caller that needs free list only)
    result = _db_rpc(project, "agent_working.next_free", {
        "role": role, "pool_size": str(pool_size)
    })
    return result.get("agent_id")
```

**兼容性**: 所有调用方 (`freely` L6014-6065) 都有 `raw_key` 可用，传入即可。无 raw_key 的调用方（如 scan）继续用旧路径，但 scan 不分配只查询 → 安全。

### F5: Reviewer 注册失败可观测 (agent_working.py)

当前 `acp_session_register` 对 reviewer 调用 `agent_assign` → `agent_working.upsert`。但 reviewer 的 `raw_key` 行可能不存在（Worker 未创建）→ INSERT 会创建只有 `reviewer_id` 的行 → OK（创建新行而不是 UPDATE ONLY）。

**实际 gap**: 文档注释说 UPDATE ONLY 但代码 default 是 upsert。问题不在 reviewer 的注册本身，而在 reviewer 写入的 `agent_assign` 使用 `upsert_only` 时的静默失败。

**修复**: 移除 `agent_assign` 中 `update_only` 参数和 `upsert_only` RPC 路径。Reviewer 注册失败应使用 `agent_working.upsert`（INSERT_OR_UPDATE），确保行不存在时自动创建。
