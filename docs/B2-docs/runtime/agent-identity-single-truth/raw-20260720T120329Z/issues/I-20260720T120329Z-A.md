# I-20260720T120329Z-A: DB 基础设施补齐

- source_candidate: docs/B1-docs/raw-20260720T120329Z/candidates.md#C-20260720T120329Z-A

## Summary

补齐 `agent_working` 表基础设施的 3 个缺口，为 C-B（运行时 agent-id.env 退役）提供稳定的 DB 接口：

1. **新增 reviews 表 + record_review/get_reviews RPC** — 修复缺陷 #5（Reviewer verdict 无法持久化）
2. **agent_next_free 切换到原子分配** — 修复缺陷 #8（TOCTOU 并发重复分配）
3. **移除 reviewer upsert_only 路径** — 修复缺陷 #6（Reviewer 注册行不存在时静默失败）

## Changes

### File 1: `docs/system/workspace/scripts/runtime/freely_db_manager.py`

#### A. 新增 reviews 表 (`_ensure_tables`)
在 `agent_working` 表创建后添加：
```sql
CREATE TABLE IF NOT EXISTS reviews (
    id INTEGER PRIMARY KEY AUTOINCREMENT,
    raw_key TEXT NOT NULL,
    review_stage TEXT NOT NULL,
    verdict TEXT NOT NULL,
    reviewed_by TEXT NOT NULL,
    reviewed_at TEXT NOT NULL DEFAULT (datetime('now')),
    findings TEXT DEFAULT '[]',
    UNIQUE(raw_key, review_stage)
)
CREATE INDEX IF NOT EXISTS idx_reviews_raw_key ON reviews(raw_key)
```

#### B. 新增 record_review RPC handler
```python
@_h("agent_working.record_review")
def h_aw_record_review(daemon, params):
```
UPSERT by (raw_key, review_stage)。调用方签名已确定：`agent_working.py:agent_record_review()` (L282-304)。

#### C. 新增 get_reviews RPC handler
```python
@_h("agent_working.get_reviews")
def h_aw_get_reviews(daemon, params):
```
返回 `{reviews: {stage: {verdict, reviewed_by, reviewed_at, findings}}}`。

### File 2: `docs/system/workspace/scripts/runtime/agent_working.py`

#### D. agent_next_free 原子化 (L251-258)
`_db_rpc("agent_working.next_free")` → `_db_rpc("agent_working.next_free_and_assign")`，新增 `raw_key` 参数。
所有 shell 调用方都有 raw_key → 兼容。

#### E. 移除 upsert_only 路径
`agent_assign` 移除 `update_only` 参数。Reviewer 注册一律使用 `agent_working.upsert`（INSERT_OR_UPDATE），确保行不存在时自动创建。
