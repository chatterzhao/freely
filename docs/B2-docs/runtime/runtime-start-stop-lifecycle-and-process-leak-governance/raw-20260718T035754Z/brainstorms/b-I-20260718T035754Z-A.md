## 方案
`_ensure_acp_bridge_running()` PATH fallback 成功后用 `upsert_config_key "$project" "$_config_key" "$acp_bin"` 回写 config.toml。`|| true` 保护（upsert_config_key 可能因 freely_config.py 不可用而失败，非致命）。
只在 PATH fallback 分支回写（config 已有值时跳过，幂等）。

## 边界
不改 resolution 链/init 流程。worker 工位启 bridge 时若主仓 config 已有值，config 读优先于 PATH 搜索。首次自愈后后续启动均命中缓存。
