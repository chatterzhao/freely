## 实现

- `runtime/consume_worker_tasks.py`：TSV 输出改 **JSON Lines**（`json.dumps` 紧凑单行），删除 `except: pass`；畸形/不完整行报 stderr + `skipped/emitted` 计数后跳过。
- 新增 `runtime/decode_worker_tasks.py`：每条 JSON 记录解码成 **6 个 NUL 分隔字段**（task_id/message/worktree/branch/raw_key/skill），畸形行报 stderr 并跳过。
- `runtime/freely` 派发循环：`while IFS=$'\t' read -r` → 6 次 `IFS= read -r -d ''` 从 NUL 流读取；**循环体逐字未动**，上游 `|| true` 语义保留，emitter/decoder 的 stderr 进 daemon 日志。
- 新增 `quality/python-c-boundary-lint.py`：只识别 R22 已实证可利用的形态（`python3 -c` 体内单引号字符串含 `$var`），输出候选清单与 count；全仓基线 **108**（runtime 目录 63）。
- 新增 `scripts/tests/test-worker-task-json-boundary.py`（AT-001，16 项）。

## 不退化边界

- 派发循环体逐字未改；`launched_count` 统计与 6 字段名称/顺序/语义不变。
- `freely` 里另外 3 处 `IFS=$'\t'`（prompt rank / worktree 列表 / 平台状态）逐字未动。
- `|| true` 保留「上游不可用 == 无待派发任务」的历史语义；上游 stderr 仍吞掉，emitter/decoder stderr 保留在日志。
- R22 的 argv/heredoc 安全形式未被 lint 误报（AT-001 B7），`test-external-input-boundary.py` 全绿。
- 未做状态文件协议迁移（拆 #4252）、未机械替换 108 个 lint 候选、未改 `load_meta_env_snapshot`。
