## 实现

- 文件头新增 `_FREELY_IS_SOURCED`：只有**直接执行**时才 `set -euo pipefail`；被 source 时保持调用方的 shell 选项。
- 两个库加载块（watchdog availability / session evidence resolver）去掉 `exit 1` 字面量：sourced 时设 `FREELY_LIB_LOAD_ERROR` 并 `return 1`；直接执行时依赖已生效的 `set -e`，用 `false` 以 1 退出（行为与旧 `exit 1` 一致）。
- `stop_project_runtime` 内 `acquire_project_start_lock_or_wait ... "freely_stop" || exit 1` 改为 `|| return 1`，锁超时不再终止复用它的 `cmd_stop`/`cmd_restart`/`cmd_task_mode set` 之外的调用方。
- 新增 `docs/system/workspace/scripts/tests/test-source-safe-library.py`（AT-001，6 项）。

## 不退化边界

- 直接执行路径行为不变：缺库仍以 1 退出、`main` 守卫不变。
- 库函数集合不变（source 后 `cmd_start` 等仍可用）。
- 未拆 26,823 行单体、未迁 skills 库、未改 551 个测试语义（issue 明确非目标）。
- `bash -n` 通过；4 个已知 source 调用方语法通过。
