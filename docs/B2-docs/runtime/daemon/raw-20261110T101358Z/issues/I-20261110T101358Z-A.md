## 实现

- `runtime/a2a_task.py` 文件头新增 `from __future__ import annotations`（带 #4272 说明），使 `:435` 的 `-> SSEPool` 前向引用延迟求值，模块不再在导入时抛 `NameError`。修复后 `list` / `update` 返回**明确业务错误**（A2A Server 未启动）而非 traceback。
- 新增 `tests/test-a2a-task-cli-loadable.py`（AT-001，8 项），并同时加入 `bin/test-all` 的 `CORE` 与 `CI_CORE` 两个列表 —— 保证 `--ci` 模式也会执行，杜绝「全绿但 CLI 起不来」再次发生。
- 实测 install 态 `~/.freely/versions/latest/...` 同样失败，本轮合并后自举打包会随之修复。

## 不退化边界

- 不改 `:435` 标注文本、不挪 `SSEPool` 定义、不改 SSEPool / A2AClient 实现。
- 不改状态机语义、`--state` / `--status` 参数、派发循环、`2>/dev/null || true` 容错语义。
- 未碰 `runtime/freely` 任何一行；未改 #4254 涉及的任何文件。
- `test-reviewer-contract.py` 等既有回归全绿。

## 已知既有失败（非本轮引入）

`bin/test-all`（local 模式）仍有 `test-github-label-autocreate.py` 失败；develop 基线同样是 `8 ok / 1 failed`，属既有 known-broken。本轮加入冒烟后 local 变为 `9 ok / 1 failed`，`bin/test-all --ci` 全绿。
