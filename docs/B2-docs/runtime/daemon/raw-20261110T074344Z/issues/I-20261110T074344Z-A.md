## 实现

- `runtime/state_file.py` 新增 `values <path> <keys...>`（行接口，值含换行明确报错拒绝）与 `write --kv KEY=VALUE`（可重复，值经 argv 传递，不拼进脚本体）。
- `runtime/freely` 的 `_read_cooldown_state()` 去掉 `source`，改用 `{ read -r at; read -r idx; } < <(python3 state_file.py values ...)`；**不用 `mapfile`**（macOS bash 3.2 不支持）。缺文件/失败回落 0，与原 `${VAR:-0}` 语义一致。
- `_write_cooldown_state()` 去掉 `printf 'KEY=%s\n'`，改用 `write --kv`，落盘为 `KEY<TAB>json.dumps(value)`。
- 新增 `docs/system/workspace/scripts/tests/test-state-family-cooldown.py`（AT-001，8 项，source 真实 `freely` 并调用真实函数）。

## 不退化边界

- 键名与语义不变（`COOLDOWN_SWITCH_AT/INDEX`、下游 `CROSS_TOOL_SWITCH_*`）。
- 兼容旧 `KEY=value` 状态文件，不要求清空 `.freely/run/`。
- 未动其余 54 处状态 `source`、39 处非状态 `source`、`load_meta_env_snapshot`。
- 不改协议既有 `read`/`write --data`/`to-shell`/白名单行为。

## 明确不纳入

其余 54 处状态 source 与对应写入点（按族逐轮推进），位置格式文件的单独判定。已排进 goal。
