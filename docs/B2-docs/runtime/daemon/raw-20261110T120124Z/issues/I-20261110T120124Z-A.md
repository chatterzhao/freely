## 实现

1. **watchdog**（`bin/freely-watchdog`）：缺日志时自动创建；`tail -f` → `tail -F`；`PRE_CHECK_MAP ... || continue` 不再让首次违规结束 `while` 子壳；`PID_FILE` + 存活检查让二次启动为 no-op，退出清理；`WORKTREES_ROOT` 可由 `FREELY_WORKTREES_ROOT` 覆盖，不再硬编码第四套根推导。
2. **事件字段**（`runtime/freely::append_runtime_event`）：函数内按事件名映射 `severity`（error/warn/info），`trace_id` 取 `FREELY_TRACE_ID` / `FREELY_RUN_ID` + 日期；调用签名不变，120+ 调用点无需改。
3. **日志保留**：新增 `_prune_logs_by_count`；`cycle-*.log` 保留 50（`FREELY_CYCLE_LOG_KEEP`）、`crash-*.log` 保留 20（`FREELY_CRASH_LOG_KEEP`）。
4. **打包卫生**（`bin/freely-package`）：目录复制后删除 `__pycache__` 与 `*.bak.py`，`count` 改为统计产物。
5. **凭据**：`gitee-issue.py` 的 token 从 URL query 改 `Authorization: Bearer`（已用真实只读 `get IKUEK0` 验证）；`ai-cli` 的 codex bundle 写入改为 `FREELY_CODEX_API_KEY` 环境变量 + `os.environ` 读取，key 不再出现在 `ps` 的 argv。
6. **DB**（`freely_db_manager.py`）：`SCHEMA_VERSION = 1`；打开库时 `user_version > 1` 直接报错；迁移结束写 `PRAGMA user_version`；两处 `except Exception: pass` 改为 `raise RuntimeError`（`review_stage` 的 duplicate-column 是唯一允许例外）。

新增 `tests/test-obs-ops-backlog.py`（AT-001，11 项），接入 `bin/test-all` 的 `CORE` / `CI_CORE`。

## 不退化边界

- `append_runtime_event` 签名不变；`--key` CLI 语义不变（只是落盘路径不再经 argv）；#4158 的 `refuse_dangerous_output` 未改。
- `lifecycle-trace` 的 seq 语义未改；`_rotate_log` 未改，只新增按数量裁剪。
- Gitee 只读接口用真实请求验证过，未修改任何平台数据。
- 未改 `ai-cli` 的交互登录流程与槽位逻辑。
