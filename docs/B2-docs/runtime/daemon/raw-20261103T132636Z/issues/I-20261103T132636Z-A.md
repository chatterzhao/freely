## 实现

- `bin/pr-review-guarded` 两处 `python3 -c "... try_canonicalize_raw_key('$review_branch') ..."` 改为 `python3 - "$ROOT_DIR" "$review_branch" <<'PY'`，值走 `sys.argv`，脚本体是静态文本（`<<'PY'` 不做展开）。外部分支名可合法含 `'`/`;`/`$`/反引号，此前等于在 maintainer 机器上执行审查对象的代码。
- 6 处 `sed -i ''`（BSD-only；GNU sed 把 `''` 当文件名并失败）统一改 `sed -i.bak`，并在**同一条命令**追加 `rm -f "<target>.bak"`。涉及 `pr-review-guarded`、`freely`×4、`wt-create`。
- 顺带修 `wt-close:1251`：基线里已是 `sed -i.bak` 但从不清理 `.bak`，会残留污染工作树。
- 新增 `docs/system/workspace/scripts/tests/test-external-input-boundary.py`（AT-001，7 项）。

## 不退化边界

- 只替换「引号形式」，不改任何 `sed` 的替换表达式与目标文件。
- 两处 python 片段的逻辑逐行保持不变，仅把插值换成 `sys.argv`。
- 未动状态文件 `source`、TSV 派发通道、其余 195 处 `python3 -c`（拆 #4247）。
