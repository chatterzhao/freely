## 问题

`write_workcell_state()` 使用 `source "$state_file"` 读取 `LAST_ENTRYPOINT_MODE`。
当 env 文件含未引号多词值时，bash 将其解释为命令执行。

## 修复

将 `source` 替换为 `meta_env_value`（awk 安全解析），改动 4 行 → 1 行。
附带 `git rm --cached .freely/run/workcell-state.env` 移除误提交的运行时文件。
