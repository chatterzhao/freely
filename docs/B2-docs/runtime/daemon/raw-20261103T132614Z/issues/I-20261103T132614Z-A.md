## 实现

- 新增 `runtime/paths.sh`：`freely_tool_registry_path` / `freely_tool_registry_query_path` 是路径唯一所有者。
- `runtime/freely` 按既有 `_freely_lib_missing` 范式 source 它，`TOOL_REGISTRY` / `TOOL_REGISTRY_QUERY` 由函数产出；`_init_acp_tool_setup` 改用 `$TOOL_REGISTRY`，注册表/查询脚本/ensure 脚本任一缺失 → `log_error` + `return 1`（旧行为是 `log_warn` + `return 0`，整段 ACP setup 静默消失）。
- `bin/deploy-skills` source 同一库；注册表缺失 → `exit 1` 并提示显式 `--tools`；删除 `[[ -z "$tools" ]] && tools="claude"` 这条静默 fallback。注册表存在但无已安装工具时打印说明并 `exit 0`（合法空集，不是猜 claude）。
- `runtime/raw_key_canon.py` 增加 legacy `YYYYMMDD-HHMM[SS]`（含 `raw-` 前缀与分支名内嵌）规范化，并新增 `__main__` CLI 供 shell 入口调用。
- `worktree/wt-create` 的验证段改调 canon：规范化失败即拒绝（不再只告警），成功则打印 normalised 并写回 `raw_key`，后续分支名/目录/scan lookup 全部使用 canonical 形式。
- 新 AT 接入 `bin/test-all` 的 `CORE` 与 `CI_CORE`。
