## 实现

- `runtime/freely`：workcell supervisor 在「无可用自动恢复路径」时从 `exit 0` 改为 `exit 1`，`supervisor_stopping` 事件补 `exit_kind=degraded_no_recovery`。外层 systemd/tmux 因此能看到失败并按重启策略处理，而不是把 workcell 消失记成正常停止。
- `bin/freely`：在 `_SCRIPT` 解析之前检查 `command -v python3` 与 `sys.version_info >= (3, 11)`；不满足时输出 `[ERROR] freely requires Python >= 3.11 (found ...)` 并 `exit 1`。13 个模块依赖 `tomllib`（3.11+），旧环境下不再以深处的 `ModuleNotFoundError` 作为首错。
- 新增 `tests/test-fail-semantics-preflight.py`（AT-001，6 项），同时接入 `bin/test-all` 的 `CORE` / `CI_CORE`。
