## 根因

宪法 §16 要求自举不自我豁免，但核心 runtime 的改动只有结果性证据：

1. `docs/system/workspace/scripts/runtime/freely` **27,272 行**，`tests/` 603 项里
   **没有 `unit/` 目录**；`test-freely-*` 全部是「建沙箱 repo → 跑 `bin/freely` →
   断言输出」，无法定位到函数。
2. `pr-create-guarded` 的 body 默认 `See commits for details.`，仓库里**连 PR
   模板都没有**（且 `gh pr create --body` 会覆盖模板），所以「RED 证据」这一栏
   从来不存在。
3. `pr-review-guarded` 775 行里只有 worktree 清洁、PR 号、路径、ACP、verdict、
   收尾清洁——没有任何 TDD 检查，缺失也不会 `needs_changes`。

## 影响

runtime 修复无法证明「先有失败测试」；回归只能靠大范围脚本测试，定位成本高；
自举公信力与托管项目不一致。

## 修复方案

1. `docs/system/workspace/scripts/tests/unit/`：`harness.sh`（`ut_load_runtime` /
   `ut_sandbox` / assert 家族 / `ut_report`）+ `run.sh`（每测试独立 bash 进程，
   累加 `SUMMARY`）。14 个测试覆盖状态机 4、锁 4、退出码 4、事件 1、DB 1。
   运行时本来就是 sourceable 库（`_FREELY_IS_SOURCED`，#4153），65ms 加载，
   **不需要重构 27k 行**。
2. `docs/system/workspace/scripts/worktree/pr_body.py`：PR body 恒带
   `## RED 证据`。有证据 → 引用验收项/命令/RED/GREEN/证据路径；diff 不碰 runtime
   → 显式写「不适用」；碰 runtime 但无证据 → exit 3，`pr-create-guarded` 拒绝建 PR。
3. `docs/system/workspace/scripts/quality/runtime_red_gate.py`：`pr-review-guarded`
   新增 Step 2.5。0=pass（有单测 + 有 RED→GREEN 证据 + 证据文件存在）、
   1=refuse（缺单测或缺证据）、2=skip（非 runtime 变更）。
4. 三个已合并修复补录 RED：SSE watchdog claim（`6715a67a2`）、runtime 事件
   severity/trace_id 与按数量清理（`83ba84a74`）、DB `user_version`（`83ba84a74`）。

## 验收标准

- RED：无 `tests/unit/`；无 `pr_body.py` / `runtime_red_gate.py`；body 为裸文案；
  review 无 RED 检查 → AT-001 `2 ok / 19 failed`。
- GREEN：AT-001 `21 ok / 0 failed`；单元语料 14 文件 / 68 断言全绿，且故意失败的
  probe 能让 runner 非零退出。
- GREEN：`pr_body.py` 三态（不适用 / exit 3 / 引用证据）与 `runtime_red_gate.py`
  三态（2 / 1 / 0）均按契约工作。
- GREEN：3 个历史修复在修复前基线上复现 RED。
- 不退化：本轮**不改 `runtime/freely` 一行**；`test-all --ci` 14/0、local 仅剩既有
  `test-github-label-autocreate.py`。
